## 1. 基本定义和倒数关系

- **基本定义：**  
  \[
  \sin \theta = \frac{\text{对边}}{\text{斜边}},\quad \cos \theta = \frac{\text{邻边}}{\text{斜边}},\quad \tan \theta = \frac{\sin \theta}{\cos \theta}.
  \]

- **倒数关系：**  
  \[
  \csc \theta = \frac{1}{\sin \theta},\quad \sec \theta = \frac{1}{\cos \theta},\quad \cot \theta = \frac{1}{\tan \theta} = \frac{\cos \theta}{\sin \theta}.
  \]

---

## 2. 奇偶性（对称性）

- **偶函数与奇函数：**  
  \[
  \sin(-\theta) = -\sin\theta,\quad \cos(-\theta) = \cos\theta,\quad \tan(-\theta) = -\tan\theta.
  \]

- **互补角恒等式：**  
  \[
  \sin\left(\frac{\pi}{2} - \theta\right) = \cos\theta,\quad \cos\left(\frac{\pi}{2} - \theta\right) = \sin\theta,\quad \tan\left(\frac{\pi}{2} - \theta\right) = \cot\theta.
  \]

---

## 3. 勾股恒等式

- **基本勾股恒等式：**  
  \[
  \sin^2\theta + \cos^2\theta = 1.
  \]

- **其他形式：**  
  \[
  1 + \tan^2\theta = \sec^2\theta,\quad 1 + \cot^2\theta = \csc^2\theta.
  \]

---

## 4. 和、差公式

- **正弦的和差公式：**  
  \[
  \sin(\alpha\pm\beta)=\sin\alpha\cos\beta\pm\cos\alpha\sin\beta.
  \]

- **余弦的和差公式：**  
  \[
  \cos(\alpha\pm\beta)=\cos\alpha\cos\beta\mp\sin\alpha\sin\beta.
  \]

- **正切的和差公式：**  
  \[
  \tan(\alpha\pm\beta)=\frac{\tan\alpha\pm\tan\beta}{1\mp\tan\alpha\,\tan\beta}.
  \]

---

## 5. 倍角公式

- **正弦倍角公式：**  
  \[
  \sin2\theta = 2\sin\theta\cos\theta.
  \]

- **余弦倍角公式：**  
  \[
  \cos2\theta = \cos^2\theta - \sin^2\theta = 2\cos^2\theta - 1 = 1 - 2\sin^2\theta.
  \]

- **正切倍角公式：**  
  \[
  \tan2\theta = \frac{2\tan\theta}{1-\tan^2\theta}.
  \]

---

## 6. 半角公式

- **正弦半角公式：**  
  \[
  \sin^2\frac{\theta}{2} = \frac{1-\cos\theta}{2},\quad \sin\frac{\theta}{2} = \pm\sqrt{\frac{1-\cos\theta}{2}}.
  \]

- **余弦半角公式：**  
  \[
  \cos^2\frac{\theta}{2} = \frac{1+\cos\theta}{2},\quad \cos\frac{\theta}{2} = \pm\sqrt{\frac{1+\cos\theta}{2}}.
  \]

- **正切半角公式：**  
  \[
  \tan\frac{\theta}{2} = \frac{\sin\theta}{1+\cos\theta} = \frac{1-\cos\theta}{\sin\theta}.
  \]

---

## 7. 积化和差公式（积到和、和到积）

- **积化和差：**  
  \[
  \sin\alpha\cos\beta = \frac{1}{2}[\sin(\alpha+\beta) + \sin(\alpha-\beta)],
  \]
  \[
  \cos\alpha\cos\beta = \frac{1}{2}[\cos(\alpha+\beta) + \cos(\alpha-\beta)],
  \]
  \[
  \sin\alpha\sin\beta = \frac{1}{2}[\cos(\alpha-\beta) - \cos(\alpha+\beta)].
  \]

- **和差化积：**  
  \[
  \sin\alpha+\sin\beta = 2\sin\frac{\alpha+\beta}{2}\cos\frac{\alpha-\beta}{2},
  \]
  \[
  \sin\alpha-\sin\beta = 2\cos\frac{\alpha+\beta}{2}\sin\frac{\alpha-\beta}{2},
  \]
  \[
  \cos\alpha+\cos\beta = 2\cos\frac{\alpha+\beta}{2}\cos\frac{\alpha-\beta}{2},
  \]
  \[
  \cos\alpha-\cos\beta = -2\sin\frac{\alpha+\beta}{2}\sin\frac{\alpha-\beta}{2}.
  \]

---

## 8. 其他常见公式

- **辅助公式：**  
  \[
  \sec\theta - \tan\theta = \frac{1-\sin\theta}{\cos\theta},
  \]
  \[
  \csc\theta - \cot\theta = \frac{1-\cos\theta}{\sin\theta}.
  \]

- **反三角函数的关系：**（常用于推导）  
  \[
  \arcsin x + \arccos x = \frac{\pi}{2},
  \]
  \[
  \arctan x + \arctan\frac{1}{x} = \frac{\pi}{2}\quad (x>0).
  \]

### **一、基本定义**
1. **直角三角形定义**（锐角）
   - 正弦：sinθ = 对边/斜边
   - 余弦：cosθ = 邻边/斜边
   - 正切：tanθ = 对边/邻边
   - 余切：cotθ = 邻边/对边
   - 正割：secθ = 斜边/邻边
   - 余割：cscθ = 斜边/对边

2. **单位圆定义**（任意角θ）
   - 若角θ终边与单位圆交点为 (x, y)，则：
     - sinθ = y
     - cosθ = x
     - tanθ = y/x（x≠0）

---

### **二、基本三角函数**
1. **六种三角函数关系**
   - 倒数关系：  
     sinθ = 1/cscθ, cosθ = 1/secθ, tanθ = 1/cotθ
   - 商数关系：  
     tanθ = sinθ/cosθ, cotθ = cosθ/sinθ

2. **特殊角的值**
   - 0°, 30°, 45°, 60°, 90° 的正弦、余弦、正切值表

---

### **三、三角函数性质**
1. **周期性**
   - sinθ, cosθ 周期为 2π
   - tanθ, cotθ 周期为 π

2. **奇偶性**
   - 奇函数：sinθ, tanθ, cotθ, cscθ
   - 偶函数：cosθ, secθ

3. **幅度与范围**
   - sinθ, cosθ ∈ [-1, 1]
   - tanθ ∈ ℝ（除π/2 + kπ）

4. **象限符号规则**
   - 各象限中三角函数的正负性

---

### **四、三角恒等式**
1. **基本恒等式**
   - 毕达哥拉斯恒等式：  
     sin²θ + cos²θ = 1  
     1 + tan²θ = sec²θ  
     1 + cot²θ = csc²θ

2. **和差公式**
   - sin(α±β) = sinαcosβ ± cosαsinβ
   - cos(α±β) = cosαcosβ ∓ sinαsinβ

3. **倍角与半角公式**
   - 倍角：sin2θ = 2sinθcosθ, cos2θ = cos²θ - sin²θ
   - 半角：sin²(θ/2) = (1 - cosθ)/2, cos²(θ/2) = (1 + cosθ)/2

4. **积化和差与和差化积**
   - sinαcosβ = [sin(α+β) + sin(α-β)] / 2
   - sinα + sinβ = 2sin[(α+β)/2]cos[(α-β)/2]

### **五、反三角函数**
1. **定义与主值**

### **一、基本公式**
1. **勾股定理**（毕达哥拉斯定理）  
   \[
   a^2 + b^2 = c^2
   \]  
   - \(a, b\) 为直角边，\(c\) 为斜边。

2. **周长公式**  
   \[
   \text{周长} = a + b + c
   \]

3. **面积公式**  
   \[
   \text{面积} = \frac{1}{2} \times a \times b
   \]

---

### **二、三角函数关系**
1. **基本三角函数**（针对锐角 \(\theta\)）：  
   - 正弦：\(\sin\theta = \frac{\text{对边}}{\text{斜边}} = \frac{a}{c}\)  
   - 余弦：\(\cos\theta = \frac{\text{邻边}}{\text{斜边}} = \frac{b}{c}\)  
   - 正切：\(\tan\theta = \frac{\text{对边}}{\text{邻边}} = \frac{a}{b}\)  
   - 余切：\(\cot\theta = \frac{\text{邻边}}{\text{对边}} = \frac{b}{a}\)  
   - 正割：\(\sec\theta = \frac{\text{斜边}}{\text{邻边}} = \frac{c}{b}\)  
   - 余割：\(\csc\theta = \frac{\text{斜边}}{\text{对边}} = \frac{c}{a}\)

2. **反三角函数**（已知比例求角度）：  
   - \(\theta = \arcsin\left(\frac{a}{c}\right)\)  
   - \(\theta = \arccos\left(\frac{b}{c}\right)\)  
   - \(\theta = \arctan\left(\frac{a}{b}\right)\)

---

### **三、斜边上的高与中线**
1. **斜边上的高**（\(h\)）  
   \[
   h = \frac{a \times b}{c}
   \]
   - 推导：由面积公式 \( \frac{1}{2} a b = \frac{1}{2} c h \)。

2. **斜边上的中线**（\(m_c\)）  
   \[
   m_c = \frac{c}{2}
   \]
   - 直角三角形的斜边中线等于斜边的一半。

---

### **四、内切圆与外接圆**
1. **外接圆半径**（\(R\)）  
   \[
   R = \frac{c}{2}
   \]
   - 直角三角形的外接圆圆心在斜边中点。

2. **内切圆半径**（\(r\)）  
   \[
   r = \frac{a + b - c}{2}
   \]
   - 推导：由面积公式 \( r = \frac{\text{面积}}{\text{半周长}} \)。

---

### **五、特殊直角三角形的边长比例**
1. **等腰直角三角形**（45°-45°-90°三角形）  
   - 边长比例：\(1 : 1 : \sqrt{2}\)  
   - 若直角边为 \(k\)，则斜边为 \(k\sqrt{2}\)。

2. **30°-60°-90°三角形**  
   - 边长比例：\(1 : \sqrt{3} : 2\)  
   - 若最短边（对30°角）为 \(k\)，则斜边为 \(2k\)，较长边为 \(k\sqrt{3}\)。

---

### **六、勾股数与扩展公式**
1. **常见勾股数**  
   - 基本三元组：\((3, 4, 5)\)、\((5, 12, 13)\)、\((7, 24, 25)\) 等。  
   - 通用生成公式：\(a = m^2 - n^2\)，\(b = 2mn\)，\(c = m^2 + n^2\)（\(m > n > 0\)）。

2. **扩展勾股定理**（三维空间）  
   - 长方体对角线长度：  
     \[
     d = \sqrt{a^2 + b^2 + c^2}
     \]

---

### **七、应用实例**
1. **已知两边求第三边**  
   - 若 \(a=3\)，\(b=4\)，则斜边 \(c = \sqrt{3^2 + 4^2} = 5\)。

2. **已知斜边与一角求直角边**  
   - 若 \(c=10\)，\(\theta=30^\circ\)，则对边 \(a = c \cdot \sin30^\circ = 5\)，邻边 \(b = c \cdot \cos30^\circ = 5\sqrt{3}\)。

---

### **八、总结**
直角三角形的公式涵盖了从基本定理到三角函数的广泛内容，是几何学、物理学和工程学的重要基础。建议结合具体问题（如测量高度、计算角度）练习应用这些公式，以加深理解！

以下是常用几何图形的方程总结，涵盖笛卡尔方程、参数方程、极坐标方程及三维扩展，按分类整理：

---

### **一、二维图形**
#### **1. 直线**
- **一般式**：\( Ax + By + C = 0 \)
- **斜截式**：\( y = mx + b \)  
  （斜率 \( m \)，截距 \( b \)）
- **点斜式**：\( y - y_1 = m(x - x_1) \)  
  （过点 \( (x_1, y_1) \)）
- **参数方程**：  
  \[
  \begin{cases}
  x = x_0 + at \\
  y = y_0 + bt
  \end{cases} \quad (t \in \mathbb{R})
  \]  
  （方向向量 \( (a, b) \)，起点 \( (x_0, y_0) \)）
- **向量方程**：\( \mathbf{r} = \mathbf{r_0} + t\mathbf{v} \)

---

#### **2. 圆**
- **标准方程**：  
  \[
  (x - h)^2 + (y - k)^2 = r^2
  \]  
  （圆心 \( (h, k) \)，半径 \( r \)）
- **参数方程**：  
  \[
  \begin{cases}
  x = h + r\cos\theta \\
  y = k + r\sin\theta
  \end{cases} \quad (\theta \in [0, 2\pi))
  \]
- **极坐标方程**：  
  \[
  r = 2R\cos(\theta - \alpha) \quad (\text{圆心在极坐标系中为} (R, \alpha))
  \]

---

#### **3. 椭圆**
- **标准方程**：  
  \[
  \frac{(x - h)^2}{a^2} + \frac{(y - k)^2}{b^2} = 1
  \]  
  （中心 \( (h, k) \)，长轴 \( 2a \)，短轴 \( 2b \)）
- **参数方程**：  
  \[
  \begin{cases}
  x = h + a\cos\theta \\
  y = k + b\sin\theta
  \end{cases} \quad (\theta \in [0, 2\pi))
  \]
- **极坐标方程**（以焦点为原点）：  
  \[
  r = \frac{a(1 - e^2)}{1 + e\cos\theta} \quad (e = \sqrt{1 - \frac{b^2}{a^2}})
  \]

---

#### **4. 抛物线**
- **标准方程**（开口向上）：  
  \[
  (x - h)^2 = 4p(y - k)
  \]  
  （顶点 \( (h, k) \)，焦点距离顶点 \( p \)）
- **参数方程**：  
  \[
  \begin{cases}
  x = h + 2pt \\
  y = k + pt^2
  \end{cases} \quad (t \in \mathbb{R})
  \]

---

#### **5. 双曲线**
- **标准方程**（水平开口）：  
  \[
  \frac{(x - h)^2}{a^2} - \frac{(y - k)^2}{b^2} = 1
  \]
- **参数方程**（用双曲函数）：  
  \[
  \begin{cases}
  x = h + a\cosh t \\
  y = k + b\sinh t
  \end{cases} \quad (t \in \mathbb{R})
  \]
- **极坐标方程**（以右焦点为原点）：  
  \[
  r = \frac{a(e^2 - 1)}{1 + e\cos\theta} \quad (e > 1)
  \]

---

#### **6. 正多边形**
- **正n边形的极坐标方程**（中心在原点）：  
  \[
  r = R \quad \text{（边数为偶数）} \\
  \text{或分段方程描述各边}
  \]
- **正三角形顶点坐标**（边长为 \( a \)）：  
  \[
  \left(0, 0\right), \left(a, 0\right), \left(\frac{a}{2}, \frac{\sqrt{3}a}{2}\right)
  \]

---

### **二、三维图形**
#### **1. 平面**
- **一般式**：\( Ax + By + Cz + D = 0 \)
- **点法式**：\( \mathbf{n} \cdot (\mathbf{r} - \mathbf{r_0}) = 0 \)  
  （法向量 \( \mathbf{n} = (A, B, C) \)，过点 \( \mathbf{r_0} \)）

---

#### **2. 球体**
- **标准方程**：  
  \[
  (x - a)^2 + (y - b)^2 + (z - c)^2 = r^2
  \]  
  （球心 \( (a, b, c) \)，半径 \( r \)）
- **参数方程**（球坐标系）：  
  \[
  \begin{cases}
  x = a + r\sin\phi\cos\theta \\
  y = b + r\sin\phi\sin\theta \\
  z = c + r\cos\phi
  \end{cases} \quad (\theta \in [0, 2\pi), \phi \in [0, \pi))
  \]

---

#### **3. 圆柱体**
- **标准方程**（z轴为对称轴）：  
  \[
  x^2 + y^2 = r^2 \quad (z \in \mathbb{R})
  \]
- **参数方程**：  
  \[
  \begin{cases}
  x = r\cos\theta \\
  y = r\sin\theta \\
  z = t
  \end{cases} \quad (\theta \in [0, 2\pi), t \in \mathbb{R})
  \]

---

#### **4. 圆锥**
- **标准方程**（顶点在原点，z轴为对称轴）：  
  \[
  z^2 = k^2(x^2 + y^2)
  \]
- **参数方程**：  
  \[
  \begin{cases}
  x = t\cos\theta \\
  y = t\sin\theta \\
  z = kt
  \end{cases} \quad (t \in \mathbb{R}, \theta \in [0, 2\pi))
  \]

---

### **三、极坐标曲线**
#### **1. 心形线（Cardioid）**
- **方程**：  
  \[
  r = a(1 + \cos\theta) \quad \text{或} \quad r = a(1 - \cos\theta)
  \]

#### **2. 玫瑰线（Rose Curve）**
- **方程**：  
  \[
  r = a\cos(k\theta) \quad \text{或} \quad r = a\sin(k\theta)
  \]  
  （\( k \) 控制花瓣数量）

#### **3. 阿基米德螺线**
- **方程**：  
  \[
  r = a + b\theta \quad (a, b \in \mathbb{R})
  \]

---

### **四、参数曲线**
#### **1. 摆线（Cycloid）**
- **参数方程**：  
  \[
  \begin{cases}
  x = r(\theta - \sin\theta) \\
  y = r(1 - \cos\theta)
  \end{cases} \quad (\theta \in \mathbb{R})
  \]

#### **2. 星形线（Astroid）**
- **参数方程**：  
  \[
  \begin{cases}
  x = a\cos^3\theta \\
  y = a\sin^3\theta
  \end{cases} \quad (\theta \in [0, 2\pi))
  \]

---

### **五、隐式方程**
- **笛卡尔叶形线**：  
  \[
  x^3 + y^3 - 3axy = 0
  \]
- **双纽线**：  
  \[
  (x^2 + y^2)^2 = a^2(x^2 - y^2)
  \]

---

### **六、实用提示**
1. **参数方程中的参数范围**需明确（如角度通常为 \([0, 2\pi)\)）。
2. **三维图形**的方程可扩展至更高维度。
3. **极坐标与笛卡尔坐标转换**：  
   \[
   x = r\cos\theta, \quad y = r\sin\theta, \quad r = \sqrt{x^2 + y^2}
   \]

## 额外三角函数应用
![alt text](image.png)

### **1. 参数定义**
- **R**：圆或椭圆的半径（假设图中为圆，若为椭圆需区分长/短半轴）
- **L**：允许的最大误差（路径与曲线的最远距离）
- **S**：所需的直线段数

---

### **2. 几何模型**
- 将圆周分成 **S** 等分，每段对应圆心角 **θ = 2π/S**
- 每段直线（弦）的中点到圆心的距离为 **R - L**
- 通过三角函数建立关系：
  ```plaintext
  cos(θ/2) = (R - L)/R → θ = 2 * arccos(1 - L/R)
  ```
- 最终段数公式：
  ```plaintext
  S = π / arccos(1 - L/R)
  ```

---

### **3. 示例验证**
- 已知 **R = 100px**, **L = 0.25px**：
  ```plaintext
  S = π / arccos(1 - 0.25/100) ≈ π / arccos(0.9975) ≈ 44 段
  ```
- **几何意义**：每段弦的中点到圆心的距离为 **99.75px**，保证直线与圆的最大距离不超过 **0.25px**

---

### **4. 应用场景**
- **计算机图形学**：矢量图形的渲染优化（如字体轮廓）
- **工程制图**：复杂曲线的近似简化
- **动画路径**：平滑运动轨迹的分段控制

---

### **5. 注意事项**
- **椭圆扩展**：若为椭圆，需分别处理长轴（a）和短轴（b），公式调整为：
  ```plaintext
  S_ellipse = π / (a * arccos(1 - L/a)) + π / (b * arccos(1 - L/b))
  ```
- **误差控制**：L过大会导致锯齿明显，L过小则段数过多（计算成本上升）

## MiterLimit
![alt text](image-1.png)
![alt text](image-2.png)
### **1. 核心问题**
当对多边形进行偏移（Offset）时，若顶点处的内角 **β** 过小，斜接点（Miter Point）会因为**斜接距离（λ×δ）**过大而远离原始顶点，导致路径不连续或不符合设计要求。此时需将斜接转换为方接（Squared Join）以保证路径稳定性。

---

### **2. 关键参数与公式**
- **δ**：偏移距离（Offset Distance）
- **λ**：相对斜接距离系数（Miter Limit Ratio）
- **β**：安全允许的最大内角（Safe Miter Angle）

#### **安全条件公式**
当斜接距离 **λ×δ** ≤ 允许的最大偏移误差时，采用斜接；否则改用方接。  
通过几何关系推导出安全角度 **β** 的计算公式：
\[
\cos(\beta) = \frac{2}{\lambda^2} - 1 \quad \Rightarrow \quad \beta = \arccos\left(\frac{2}{\lambda^2} - 1\right)
\]

#### **示例验证（λ=2）**
代入公式：
\[
\cos(\beta) = \frac{2}{2^2} - 1 = \frac{2}{4} - 1 = -0.5 \quad \Rightarrow \quad \beta = 120^\circ
\]
当内角 **β ≤ 120°** 时，斜接距离 **λ×δ** 不会超过安全阈值。

---

### **3. 图形元素解析**
1. **三角形与角度标注**  
   - **β**：多边形顶点的内角，需控制在安全范围内。
   - **δ**：偏移距离，决定斜接的基本长度。

2. **公式推导步骤**  
   - **几何构造**：通过三角形相似性推导斜接距离与角度的关系。
   - **极限条件**：当斜接距离达到临界值（λ×δ）时，对应的角度即为安全阈值 **β**。

3. **颜色标注**  
   - **绿色/黄色/蓝色**：区分公式参数（δ、λ）、中间变量（ρ、σ）和计算结果（β）。

---

### **4. 斜接与方接的选择逻辑**
- **斜接（Mitered Join）**：  
  当内角 **β ≤ 安全阈值** 时，使用斜接以保证路径平滑性。
- **方接（Squared Join）**：  
  当内角 **β < 安全阈值** 或斜接距离超出限制时，切换为方接，避免偏移点偏移过大。

---

### **5. 实际应用场景**
- **CAD/CAM设计**：控制机械零件的齿形或凹槽偏移精度。
- **字体渲染**：矢量字体的斜边光滑处理。
- **游戏开发**：多边形碰撞体的偏移计算。

---

### **6. 注意事项**
- **椭圆偏移扩展**：对椭圆需分别计算长轴和短轴的安全角度。
- **数值稳定性**：当 **λ < 1** 时，可能出现无解情况（需调整λ或改用方接）。

---

### **总结**
该图通过几何建模和公式推导，提供了偏移多边形时斜接安全角度的计算方法，帮助工程师在设计中平衡路径平滑性与几何稳定性。核心思想是通过数学约束避免因局部角度过小导致的路径异常。
