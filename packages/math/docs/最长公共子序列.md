## 1. 最长公共子序列 (Longest Common Subsequence, LCS)

### **算法原理**
- **定义**：给定两个序列，找到两个序列中都出现的子序列（不要求连续），使得该子序列的长度最长。
- **关键**：使用动态规划构造一个二维数组 `dp[i][j]`，表示字符串 `s1` 的前 `i` 个字符与字符串 `s2` 的前 `j` 个字符之间的最长公共子序列长度。

### **计算步骤**
1. **初始化**  
   建立大小为 `(m+1) x (n+1)` 的二维数组 `dp`，其中 `m` 和 `n` 分别为两个字符串的长度。令所有 `dp[0][j] = 0` 和 `dp[i][0] = 0`。

2. **状态转移**  
   对于 `i = 1` 到 `m`，`j = 1` 到 `n`：
   - 如果 `s1[i-1] == s2[j-1]`，说明两个字符相同，则：
     \[
     dp[i][j] = dp[i-1][j-1] + 1
     \]
   - 否则，选择上方或左边较大的值：
     \[
     dp[i][j] = \max(dp[i-1][j],\ dp[i][j-1])
     \]

3. **构造答案**  
   最终 `dp[m][n]` 为 LCS 的长度。如果需要找出具体序列，可以从 `dp` 数组倒推回溯。

### **示例**
假设：
- `s1 = "ABCBDAB"`
- `s2 = "BDCABA"`

计算过程（部分）：
- 初始化：`dp[0][*]=0, dp[*][0]=0`
- 当 `s1[0]=='A'` 和 `s2[?]` 比较，依次更新 dp 表…
- 最终得到 LCS 长度为 4，对应的一个 LCS 如 `"BCBA"`（注意不同回溯可能得到不同的子序列）。

```javascript

function longestCommonSubsequence(s1, s2) {
  const m = s1.length, n = s2.length;
  const dp = Array.from({ length: m + 1 }, () => Array(n + 1).fill(0));

  // 构造 dp 表
  for (let i = 1; i <= m; i++) {
    for (let j = 1; j <= n; j++) {
      if (s1[i - 1] === s2[j - 1]) {
        dp[i][j] = dp[i - 1][j - 1] + 1;
      } else {
        dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
      }
    }
  }

  // 回溯构造 LCS 字符串
  let i = m, j = n;
  let lcs = "";
  while (i > 0 && j > 0) {
    if (s1[i - 1] === s2[j - 1]) {
      lcs = s1[i - 1] + lcs;
      i--;
      j--;
    } else if (dp[i - 1][j] > dp[i][j - 1]) {
      i--;
    } else {
      j--;
    }
  }

  return { length: dp[m][n], sequence: lcs };
}

// 示例
const s1 = "ABCBDAB";
const s2 = "BDCABA";
const resultLCS = longestCommonSubsequence(s1, s2);
console.log("LCS 长度：", resultLCS.length);
console.log("LCS 序列：", resultLCS.sequence);
```

## 2. 最长公共子串 (Longest Common Substring)

### **算法原理**
- **定义**：找出两个字符串中最长的公共连续子串。
- **关键**：使用动态规划构造二维数组 `dp[i][j]`，其中 `dp[i][j]` 表示以 `s1[i-1]` 和 `s2[j-1]` 结尾的公共子串的长度。

### **计算步骤**
1. **初始化**  
   建立大小为 `(m+1) x (n+1)` 的二维数组，全部初始化为 0。

2. **状态转移**  
   对于 `i = 1` 到 `m`，`j = 1` 到 `n`：
   - 如果 `s1[i-1] === s2[j-1]`，则：
     \[
     dp[i][j] = dp[i-1][j-1] + 1
     \]
   - 否则，`dp[i][j] = 0`（因为不连续）。
   - 同时维护一个全局变量 `maxLen` 和 `endIndex` 来记录最长公共子串的长度及其结束位置。

3. **构造答案**  
   利用 `endIndex` 和 `maxLen` 得到最长公共子串。

### **示例**
假设：
- `s1 = "ABABC"`
- `s2 = "BABCA"`

最长公共子串为 `"BABC"`，长度为 4。

### **JS 代码实现**

```javascript
function longestCommonSubstring(s1, s2) {
  const m = s1.length, n = s2.length;
  const dp = Array.from({ length: m + 1 }, () => Array(n + 1).fill(0));
  let maxLen = 0, endIndex = 0;

  for (let i = 1; i <= m; i++) {
    for (let j = 1; j <= n; j++) {
      if (s1[i - 1] === s2[j - 1]) {
        dp[i][j] = dp[i - 1][j - 1] + 1;
        if (dp[i][j] > maxLen) {
          maxLen = dp[i][j];
          endIndex = i;  // 记录 s1 中最长子串的结束位置
        }
      } else {
        dp[i][j] = 0;
      }
    }
  }

  const substring = s1.substring(endIndex - maxLen, endIndex);
  return { length: maxLen, substring };
}

// 示例
const s1_sub = "ABABC";
const s2_sub = "BABCA";
const resultLCSstr = longestCommonSubstring(s1_sub, s2_sub);
console.log("最长公共子串长度：", resultLCSstr.length);
console.log("最长公共子串：", resultLCSstr.substring);
```

## 3. 最长递增子序列 (Longest Increasing Subsequence, LIS)

### **算法原理**
- **定义**：在给定的数列中，找出一个子序列（不要求连续）使得其严格递增且长度最大。
- **关键**：常用动态规划方法，维护一个 `dp` 数组，其中 `dp[i]` 表示以第 `i` 个元素结尾的最长递增子序列长度。

### **计算步骤（动态规划 O(n²)）**
1. **初始化**  
   对于数组 `arr`，初始化 `dp` 数组，每个位置至少为 1（每个单独的元素都可以形成长度为 1 的序列）。

2. **状态转移**  
   对于每个元素 `arr[i]`，检查所有之前的元素 `arr[j]` (j 从 0 到 i-1)：
   - 如果 `arr[j] < arr[i]`，则说明 `arr[i]` 可以接在 `arr[j]` 后面，更新：
     \[
     dp[i] = \max(dp[i], dp[j] + 1)
     \]

3. **构造答案**  
   整个序列的最长递增子序列长度为 `max(dp)`。如果需要序列本身，可以通过额外数组记录前驱索引，然后倒推恢复完整序列。

### **示例**
对于数组：`[10, 9, 2, 5, 3, 7, 101, 18]`  
最长递增子序列长度为 4，一个可能的序列为 `[2, 3, 7, 101]` 或 `[2, 5, 7, 101]`。

## **方法 1：动态规划 O(n²)**
**思路**：
- 使用 `dp[i]` 存储以 `arr[i]` 结尾的最长递增子序列长度。
- 维护 `prev[i]` 数组存储子序列的前驱索引，最后回溯找到 LIS。

```js
function lisDP(arr) {
    if (arr.length === 0) return { length: 0, sequence: [] };

    let dp = new Array(arr.length).fill(1);
    let prev = new Array(arr.length).fill(-1);
    let maxLen = 1, lastIndex = 0;

    for (let i = 1; i < arr.length; i++) {
        for (let j = 0; j < i; j++) {
            if (arr[i] > arr[j] && dp[i] < dp[j] + 1) {
                dp[i] = dp[j] + 1;
                prev[i] = j;
            }
        }
        if (dp[i] > maxLen) {
            maxLen = dp[i];
            lastIndex = i;
        }
    }

    let lis = [];
    while (lastIndex !== -1) {
        lis.push(arr[lastIndex]);
        lastIndex = prev[lastIndex];
    }

    return { length: maxLen, sequence: lis.reverse() };
}

// 示例
console.log(lisDP([10, 9, 2, 5, 3, 7, 101, 18]));
// 输出: { length: 4, sequence: [2, 3, 7, 18] }
```
### **复杂度**
- 时间：O(n²)
- 空间：O(n)

---

## **方法 2：二分查找 + 贪心 O(n log n)**
**思路**：
- 维护 `tail` 数组存储 LIS 的最小可能结尾，每次二分查找插入位置。
- 记录前驱索引 `prev` 并回溯得到 LIS。

```js
function lisBinarySearch(arr) {
    if (arr.length === 0) return { length: 0, sequence: [] };

    let tail = [];
    let indices = [];
    let prev = new Array(arr.length).fill(-1);

    for (let i = 0; i < arr.length; i++) {
        let num = arr[i];
        let left = 0, right = tail.length - 1;

        while (left <= right) {
            let mid = Math.floor((left + right) / 2);
            if (tail[mid] >= num) {
                right = mid - 1;
            } else {
                left = mid + 1;
            }
        }

        if (left < tail.length) {
            tail[left] = num;
            indices[left] = i;
        } else {
            tail.push(num);
            indices.push(i);
        }

        if (left > 0) {
            prev[i] = indices[left - 1];
        }
    }

    let lis = [];
    let lastIndex = indices[indices.length - 1];
    while (lastIndex !== -1) {
        lis.push(arr[lastIndex]);
        lastIndex = prev[lastIndex];
    }

    return { length: tail.length, sequence: lis.reverse() };
}

// 示例
console.log(lisBinarySearch([10, 9, 2, 5, 3, 7, 101, 18]));
// 输出: { length: 4, sequence: [2, 3, 7, 18] }
```
### **复杂度**
- 时间：O(n log n)
- 空间：O(n)

---

## **方法 3：回溯 + 记忆化递归 O(n²)**
**思路**：
- 递归搜索所有可能的递增子序列，同时用 `memo` 记录已计算结果。

```js
function lisRecursive(arr) {
    let memo = new Map();
    
    function helper(index, prevIndex) {
        if (index === arr.length) return { length: 0, sequence: [] };

        let key = `${index}-${prevIndex}`;
        if (memo.has(key)) return memo.get(key);

        let exclude = helper(index + 1, prevIndex);

        let include = { length: 0, sequence: [] };
        if (prevIndex === -1 || arr[index] > arr[prevIndex]) {
            let next = helper(index + 1, index);
            include = { length: 1 + next.length, sequence: [arr[index], ...next.sequence] };
        }

        let result = include.length > exclude.length ? include : exclude;
        memo.set(key, result);
        return result;
    }

    return helper(0, -1);
}

// 示例
console.log(lisRecursive([10, 9, 2, 5, 3, 7, 101, 18]));
// 输出: { length: 4, sequence: [2, 3, 7, 18] }
```
### **复杂度**
- 时间：O(n²) （使用记忆化降低重复计算）
- 空间：O(n²) （存储 memo）

## **方法对比**
| 方法 | 时间复杂度 | 额外空间 | 适用情况 |
|------|----------|---------|----------|
| **动态规划 O(n²)** | O(n²) | O(n) | 适用于中小规模数组 |
| **二分查找 O(n log n)** | O(n log n) | O(n) | 适用于大规模数据 |
| **递归 + 记忆化 O(n²)** | O(n²) | O(n²) | 适用于探索所有可能性 |

✅ **想尝试递归写法？** 用 **记忆化递归 O(n²)**

function longestIncreasingSubsequence(arr) {
  const n = arr.length;
  if (n === 0) return { length: 0, sequence: [] };

  // dp[i] 表示以 arr[i] 结尾的最长递增子序列的长度
  const dp = Array(n).fill(1);
  // prev 用来记录每个位置的前驱索引，便于回溯具体序列
  const prev = Array(n).fill(-1);

  let maxLen = 1, maxIndex = 0;
  for (let i = 1; i < n; i++) {
    for (let j = 0; j < i; j++) {
      if (arr[j] < arr[i] && dp[j] + 1 > dp[i]) {
        dp[i] = dp[j] + 1;
        prev[i] = j;
      }
    }
    if (dp[i] > maxLen) {

      maxIndex = i;
    }

  let k = maxIndex;
  while (k !== -1) {
    sequence.unshift(arr[k]);
    k = prev[k];
  }

  return { length: maxLen, sequence };
}

## 应用场景
最长递增子序列（**LIS，Longest Increasing Subsequence**）在许多领域有重要应用，特别是在 **动态规划、贪心算法、二分查找** 以及 **序列优化问题** 方面。以下是几个关键的 **应用场景**：

## **1. 序列优化问题**
### **🔹 1.1 俄罗斯套娃信封问题（Envelope Nesting）**
- **问题**：给定一组信封，每个信封有宽高 `(w, h)`，你可以将信封嵌套在另一个信封内（`w1 < w2` 且 `h1 < h2`）。
- **解决方法**：先按 **宽度升序**，**相同宽度按高度降序** 排序，然后对 **高度序列求 LIS**，即求最多能嵌套多少个信封。

✅ **示例**：
```js
function maxEnvelopes(envelopes) {
    envelopes.sort((a, b) => a[0] - b[0] || b[1] - a[1]);
    let heights = envelopes.map(e => e[1]);
    return lisBinarySearch(heights).length;  // 用 LIS 求解
}
```
---
### **🔹 1.2 俄罗斯方块 & 叠罗汉**
- **问题**：在俄罗斯方块或马戏团叠人游戏中，找到最高叠加方式。
- **解决方法**：使用 LIS 计算最多能叠多少块/人。

✅ **示例**：
- `arr = [1, 5, 2, 3, 4, 6, 7]` 👉 LIS 是 `[1, 2, 3, 4, 6, 7]`，最多能叠 **6 层**。

## 总结

- **最长公共子序列 (LCS)** 关注不连续的公共序列，用二维 dp 数组构造；  
- **最长公共子串** 要求连续，用 dp 数组记录连续匹配长度；  
- **最长递增子序列 (LIS)** 关注数列中递增的子序列，常用动态规划（也有 O(n log n) 方法）。
