## 有理细分成普通贝塞尔曲线细分方法

我们可以对第一个公式进行简单化：

\[
\begin{aligned}
m_{0} &= \frac{p_{0}+0.5\,p_{1}w_{3}-0.5\,p_{0}}{w_{0}+0.5\,w_{3}-0.5\,w_{0}}\\[1mm]
&=\frac{0.5\,(2p_{0}+p_{1}w_{3}-p_{0})}{0.5\,(2w_{0}+w_{3}-w_{0})}\\[1mm]
&=\frac{0.5\,(p_{0}+p_{1}w_{3})}{0.5\,(w_{0}+w_{3})}\\[1mm]
&=\frac{p_{0}+p_{1}w_{3}}{w_{0}+w_{3}}.
\end{aligned}
\]

通常在有理贝塞尔曲线中，我们会将第一个控制点的权重归一化，即令 \(w_{0}=1\)；这样就有

\[
m_{0}=\frac{p_{0}+p_{1}w_{3}}{1+w_{3}},
\]

这正好等于 \(q_{0}\) 的表达式：

\[
q_{0}=\frac{p_{0}+p_{1}w_{3}}{1+w_{3}}.
\]

因此，两个公式是相等的。


下面给出如何对有理贝塞尔曲线进行细分的方法。其基本思路是将有理贝塞尔曲线转换到齐次坐标下（homogeneous coordinates），在齐次空间中利用 De Casteljau 算法进行细分，然后再将结果投影回二维平面。下面详细介绍原理推导与 JavaScript 实现。

---
下面介绍一种常用的方法，它利用了有理贝塞尔曲线在齐次空间中的“多项式性质”以及 de Casteljau 算法来实现分割，进而“转换”为普通（非有理）贝塞尔曲线的形式。

---

### 1. 有理贝塞尔曲线的齐次表示

给定一条 n 阶有理贝塞尔曲线，其表达式为

\[
R(t)=\frac{\sum_{i=0}^{n} w_i\,P_i\,B_{i,n}(t)}{\sum_{i=0}^{n} w_i\,B_{i,n}(t)}\quad,\quad t\in[0,1],
\]
其中  
\[
B_{i,n}(t)=\binom{n}{i}t^i(1-t)^{n-i}\,,
\]
\(w_i\) 为各控制点的权重，\(P_i\) 为欧几里得坐标。

引入齐次坐标（也称“扩展”或“同伦”坐标）：
\[
\tilde{P}_i=(w_iP_i,\,w_i) \quad (i=0,1,\dots,n).
\]
则可写齐次贝塞尔曲线为
\[
\tilde{R}(t)=\sum_{i=0}^{n} \tilde{P}_i\,B_{i,n}(t).
\]
最后，原曲线由投影得到：
\[
R(t)=\left(\frac{\tilde{R}_x(t)}{\tilde{R}_w(t)},\,\frac{\tilde{R}_y(t)}{\tilde{R}_w(t)}\right).
\]

---

### 2. 在齐次空间中用 de Casteljau 算法进行细分

选定分割参数 \(t_0\in (0,1)\)（例如 \(t_0=0.5\)），对齐次控制点执行 de Casteljau 算法。具体步骤如下：

1. **初始设定：**  
   \(\tilde{P}_i^{(0)}=\tilde{P}_i,\quad i=0,\dots,n.\)

2. **递归计算：**  
   对 \(k=1,\dots,n\) 和 \(i=0,\dots,n-k\)  
   \[
   \tilde{P}_i^{(k)}=(1-t_0)\,\tilde{P}_i^{(k-1)}+t_0\,\tilde{P}_{i+1}^{(k-1)}.
   \]

3. **分割结果：**  
   此时 de Casteljau 算法不仅给出了 \(R(t_0)=\tilde{P}_0^{(n)}\)（齐次形式），而且构造了两组控制点：
   - 左段齐次控制点序列：  
     \[
     Q_i^{(h)}=\tilde{P}_0^{(i)}\quad (i=0,\dots,n).
     \]
   - 右段齐次控制点序列：  
     \[
     R_i^{(h)}=\tilde{P}_i^{(n-i)}\quad (i=0,\dots,n).
     \]

---

### 3. 从齐次控制点转换为欧几里得控制点

对每一组得到的齐次控制点（左段或右段），我们只需作透视除权：
\[
Q_i=\frac{(Q_{i,x}^{(h)},\,Q_{i,y}^{(h)})}{Q_{i,w}^{(h)}},\quad
R_i=\frac{(R_{i,x}^{(h)},\,R_{i,y}^{(h)})}{R_{i,w}^{(h)}}.
\]
这就得到了分割后两段曲线在欧几里得空间中的控制点。

**注意：** 分割后得到的两段依然是有理贝塞尔曲线的表达形式。如果在某些情况下（例如原曲线的权重经过 de Casteljau 算法后变为常数），则分割后曲线可化简为普通（非有理）贝塞尔曲线。

---

### 4. 原理总结与推导过程

- **齐次表示：**  
  有理贝塞尔曲线可视为普通 Bézier 曲线在高维（齐次）空间中的表示，控制点由 \(\tilde{P}_i=(w_iP_i,\,w_i)\) 给出。

- **细分算法：**  
  由于 de Casteljau 算法是基于线性插值的递归方法，它在齐次空间中依然成立。因此，对齐次控制点进行递归计算，可以得到两组新的齐次控制点序列，这两组分别表示原曲线在区间 \([0,t_0]\) 与 \([t_0,1]\) 上的部分。

- **透视投影：**  
  将齐次控制点序列除以其最后一维（权重）就得到欧几里得坐标下的控制点。此过程保证了拼接后的两段曲线在形状上与原曲线完全一致。

- **化简为普通曲线：**  
  如果分割后每段的齐次控制点均具有相同的权重（例如权重均为 1），那么其透视除权后就得到普通的多项式 Bézier 曲线。

整个推导过程利用了齐次（投影）思想和 de Casteljau 算法的线性不变性，从而使得有理贝塞尔曲线在细分时可“拆分”为两段独立的曲线，而这两段在适当条件下可以看作普通贝塞尔曲线。

## 1. 原理与推导

### 1.1 有理贝塞尔曲线定义

对于 n 阶有理贝塞尔曲线，其参数形式为

\[
\mathbf{P}(t)=\frac{\displaystyle\sum_{i=0}^{n} w_i\,B_{i,n}(t)\,\mathbf{P}_i}{\displaystyle\sum_{i=0}^{n} w_i\,B_{i,n}(t)}\quad,\quad t\in [0,1]
\]

其中  
- \(\mathbf{P}_i=(x_i,y_i)\) 为控制点  
- \(w_i\) 为对应的权重  
- \(B_{i,n}(t)=\binom{n}{i}t^i(1-t)^{n-i}\) 为伯恩斯坦基函数

### 1.2 转换为齐次坐标

引入齐次坐标的方法是将每个控制点与其权重“打包”，令

\[
\tilde{\mathbf{P}}_i=(w_i\,x_i,\;w_i\,y_i,\;w_i)
\]

此时有理贝塞尔曲线可以写成普通（非有理）贝塞尔曲线形式：

\[
\tilde{\mathbf{P}}(t)=\sum_{i=0}^{n} B_{i,n}(t)\,\tilde{\mathbf{P}}_i
\]

最后通过投影得到二维坐标，即

\[
\mathbf{P}(t)=\left(\frac{\tilde{P}_x(t)}{\tilde{P}_w(t)},\;\frac{\tilde{P}_y(t)}{\tilde{P}_w(t)}\right)
\]

### 1.3 利用 De Casteljau 算法细分

在齐次空间中，我们可以利用 De Casteljau 算法对曲线进行细分。具体步骤如下：

1. **构造初始齐次控制点**  
   定义第 0 层：
   \[
   \tilde{P}_i^{(0)} = \tilde{\mathbf{P}}_i,\quad i=0,\ldots,n.
   \]

2. **递归生成中间点**  
   对于 \(j=1,\ldots,n\) 以及 \(i=0,\ldots,n-j\)，定义
   \[
   \tilde{P}_i^{(j)} = (1-t)\,\tilde{P}_i^{(j-1)} + t\,\tilde{P}_{i+1}^{(j-1)}.
   \]

3. **细分结果**  
   - 左子曲线的齐次控制点为：
     \[
     L_i = \tilde{P}_0^{(i)},\quad i=0,\ldots,n.
     \]
   - 右子曲线的齐次控制点为：
     \[
     R_i = \tilde{P}_{n-i}^{(i)},\quad i=0,\ldots,n.
     \]

4. **投影回二维坐标**  
   对每个齐次控制点 \( (X,Y,W) \)，其对应的二维点为
   \[
   \left(\frac{X}{W},\,\frac{Y}{W}\right),
   \]
   同时，新权重为 \(W\)。

这样，我们就得到了细分后两条有理贝塞尔曲线的控制点和权重。

有理贝塞尔曲线（Rational Bézier Curve）是在传统贝塞尔曲线的基础上引入权重，从而更灵活地控制曲线形状的一种曲线。其公式为

  \[
  R(t) = \frac{\displaystyle\sum_{i=0}^{n} w_i\, \mathbf{P}_i\, B_i^n(t)}{\displaystyle\sum_{i=0}^{n} w_i\, B_i^n(t)}, \quad t \in [0,1],
  \]

其中：

- \(\mathbf{P}_i\) 为控制点，
- \(w_i\) 为与控制点 \(\mathbf{P}_i\) 对应的权重，
- \(B_i^n(t)\) 为 Bernstein 基函数，其表达式为

  \[
  B_i^n(t) = \binom{n}{i} t^i (1-t)^{n-i}.
  \]

### 说明

1. **引入权重的意义**  
   通过给每个控制点赋予不同的权重 \(w_i\)，有理贝塞尔曲线可以更精确地表示一些特殊曲线，比如圆锥曲线（圆、椭圆、抛物线和双曲线），这是普通贝塞尔曲线无法精确表示的。

2. **特殊情况**  
   当所有的权重 \(w_i\) 均相等时（例如都取 1），分子与分母中的权重可以约去，此时有理贝塞尔曲线退化为普通的贝塞尔曲线：
   \[
   R(t) = \sum_{i=0}^{n} \mathbf{P}_i\, B_i^n(t).
   \]

3. **应用**  
   有理贝塞尔曲线是非均匀有理B样条（NURBS, Non-Uniform Rational B-Splines）的基础，在计算机辅助设计（CAD）、计算机图形学以及工业设计等领域有广泛应用。

有理贝塞尔曲线（Rational Bézier Curve）是贝塞尔曲线的一种扩展形式，它在控制点的基础上引入了**权重**（Weight），从而能够更灵活地控制曲线形状，甚至可以精确表示圆锥曲线（如圆、椭圆、双曲线等）。以下是其核心概念的分步解释：

---

### **1. 普通贝塞尔曲线回顾**
普通贝塞尔曲线由一组控制点 \( P_0, P_1, ..., P_n \) 和伯恩斯坦基函数 \( B_{i,n}(t) \) 定义：
\[
C(t) = \sum_{i=0}^n B_{i,n}(t) \cdot P_i, \quad t \in [0,1]
\]
其中，所有权重隐式为 **1**，即所有控制点对曲线的影响相同。

---

### **2. 有理贝塞尔曲线的定义**
有理贝塞尔曲线在普通贝塞尔曲线的基础上，为每个控制点 \( P_i \) 分配了一个**权重 \( w_i \)**，其数学表达式为：
\[
C(t) = \frac{\sum_{i=0}^n B_{i,n}(t) \cdot w_i \cdot P_i}{\sum_{i=0}^n B_{i,n}(t) \cdot w_i}, \quad t \in [0,1]
\]
- **分子**：加权控制点的线性组合。
- **分母**：权重的归一化因子，确保曲线参数化的一致性。

---

### **3. 权重的作用**
- **权重调整曲线形状**：  
  增大某个控制点的权重 \( w_i \)，会使曲线更靠近该控制点；减小权重则减弱其影响。
  
  **示例**：  
  - 若 \( w_0 \) 增大，曲线起点会更贴近 \( P_0 \)。
  - 若 \( w_1 \) 趋近于0，曲线几乎忽略 \( P_1 \) 的存在。

- **退化为普通贝塞尔曲线**：  
  当所有权重 \( w_i \) 相等时，分母为常数，公式简化为普通贝塞尔曲线。

---

### **4. 核心优势：精确表示圆锥曲线**
普通贝塞尔曲线无法精确表示圆、椭圆等圆锥曲线，但有理贝塞尔曲线可以。例如：
- **圆的表示**：  
  使用二次有理贝塞尔曲线（3个控制点），通过合理设置权重，可精确构造1/4圆弧。

### **1. NURBS 曲线公式**
NURBS 曲线的数学公式如下：
\[
C(u) = \frac{\sum_{i=0}^n N_{i,p}(u) \cdot w_i \cdot P_i}{\sum_{i=0}^n N_{i,p}(u) \cdot w_i}
\]
- **参数说明**：
  - \( P_i \): 控制点（共 \( n+1 \) 个）。
  - \( w_i \): 控制点的权重。
  - \( N_{i,p}(u) \): 第 \( i \) 个 B 样条基函数，阶数（度数）为 \( p \)。
  - \( u \): 参数值，取值范围由节点向量决定。

#### **核心组件解析**
| 组件              | 作用                                                                 |
|-------------------|----------------------------------------------------------------------|
| **控制点 \( P_i \)** | 定义曲线的大致形状。                                                 |
| **权重 \( w_i \)**   | 调整控制点对曲线的影响程度（类似有理贝塞尔曲线）。                   |
| **基函数 \( N_{i,p}(u) \)** | 递归定义的函数，决定各控制点在参数 \( u \) 处的贡献。               |
| **节点向量**        | 非均匀分布的参数值序列，控制基函数的局部支撑范围。                   |

---

### **2. B样条基函数 \( N_{i,p}(u) \) 的递归定义**
基函数通过递归计算（Cox-de Boor 算法）：
\[
N_{i,0}(u) = 
\begin{cases}
1 & \text{if } u_i \leq u < u_{i+1} \\
0 & \text{otherwise}
\end{cases}
\]
\[
N_{i,p}(u) = \frac{u - u_i}{u_{i+p} - u_i} \cdot N_{i,p-1}(u) + \frac{u_{i+p+1} - u}{u_{i+p+1} - u_{i+1}} \cdot N_{i+1,p-1}(u)
\]

---

### **3. JavaScript 实现代码**
#### **(1) 基础函数：B样条基函数计算**
```javascript
function computeBasis(i, p, u, knots) {
  // 递归终止条件：0阶基函数
  if (p === 0) {
    return (knots[i] <= u && u < knots[i + 1]) ? 1 : 0;
  }

  // 计算分母，避免除以零
  const denom1 = knots[i + p] - knots[i];
  const denom2 = knots[i + p + 1] - knots[i + 1];

  let term1 = 0, term2 = 0;

  if (denom1 !== 0) {
    term1 = ((u - knots[i]) / denom1) * computeBasis(i, p - 1, u, knots);
  }

  if (denom2 !== 0) {
    term2 = ((knots[i + p + 1] - u) / denom2) * computeBasis(i + 1, p - 1, u, knots);
  }

  return term1 + term2;
}
```

#### **(2) NURBS 曲线生成函数**
```javascript
function evaluateNURBS(u, degree, controlPoints, weights, knots) {
  const n = controlPoints.length - 1; // 控制点索引最大值
  const p = degree;                   // 曲线度数（阶数-1）
  let numeratorX = 0, numeratorY = 0, denominator = 0;

  for (let i = 0; i <= n; i++) {
    const basis = computeBasis(i, p, u, knots);
    const weightedBasis = basis * weights[i];

    numeratorX += weightedBasis * controlPoints[i].x;
    numeratorY += weightedBasis * controlPoints[i].y;
    denominator += weightedBasis;
  }

  if (denominator === 0) return null; // 避免除以零

  return {
    x: numeratorX / denominator,
    y: numeratorY / denominator
  };
}
```

#### **(3) 生成完整曲线的示例**
```javascript
// 示例：二次NURBS曲线（度数p=2）
const degree = 2;
const controlPoints = [
  { x: 0, y: 0 }, { x: 2, y: 3 }, { x: 5, y: 1 }, { x: 7, y: 4 }
];
const weights = [1, 0.5, 1, 1];  // 权重数组
const knots = [0, 0, 0, 0.3, 0.7, 1, 1, 1]; // 非均匀节点向量（需满足m = n + p + 1）

// 生成曲线上100个点
const curvePoints = [];
for (let u = 0; u <= 1; u += 0.01) {
  const point = evaluateNURBS(u, degree, controlPoints, weights, knots);
  if (point) curvePoints.push(point);
}

console.log(curvePoints); // 输出曲线点坐标
```

### **4. 关键参数说明**
| 参数               | 规则                                                                 |
|--------------------|----------------------------------------------------------------------|
| **节点向量**       | 长度必须为 \( m = n + p + 1 \)，且非递减排列（例如 `[0,0,0,1,1,1]`）|
| **权重**           | 必须为正数，权重为0时等价于移除对应控制点。                          |
| **度数 \( p \)**   | 需满足 \( p \leq n \)，通常 \( p=2 \)（二次曲线）或 \( p=3 \)（三次曲线） |

---

### **5. 性能优化策略**
- **记忆化（Memoization）**：缓存已计算的基函数值，避免重复递归。
- **迭代代替递归**：将基函数计算改写为迭代形式，减少调用栈开销。
- **预计算节点向量**：对于固定节点向量，提前计算并存储基函数表。

### **总结**
NURBS 曲线的实现核心在于 **B样条基函数的递归计算** 和 **权重归一化**。通过调整控制点、权重和节点向量，可以灵活生成从简单直线到复杂曲面的几何形状。此实现可直接用于WebGL、Canvas或SVG的图形渲染场景。
