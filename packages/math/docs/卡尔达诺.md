下面是 **卡尔达诺（Cardano）公式的完整推导过程 + 每一步的具体计算步骤**。
我不会跳步，也不会只给结果，会把所有代入、变换、替换都写得 **清晰可见**。

---

# 🔥 我们要求解的一般三次方程

[
ax^3 + bx^2 + cx + d = 0 \quad (a\neq 0)
]

---

# ⭐ 第 1 步：归一化（让系数更简单）

整个方程除以 (a)：

[
x^3 + px^2 + qx + r = 0
]

其中：

[
p = \frac{b}{a}, \quad q = \frac{c}{a}, \quad r = \frac{d}{a}
]

---

# ⭐ 第 2 步：消去二次项（最重要一步）

令：

[
x = t - \frac{p}{3}
]

计算目的：把 (t^2) 项干掉。

把它代入：

[
(t - \frac{p}{3})^3 + p(t - \frac{p}{3})^2 + q(t - \frac{p}{3}) + r = 0
]

下面展开每一部分。

---

# ⭐ 第 3 步：逐项展开（不跳步）

## ① 展开立方

[
(t - \frac{p}{3})^3
= t^3 - t^2 p + t \frac{p^2}{3} - \frac{p^3}{27}
]

## ② 展开平方项

[
(t - \frac{p}{3})^2 = t^2 - \frac{2p}{3} t + \frac{p^2}{9}
]

乘上 p：

[
p(t - \frac{p}{3})^2
= p t^2 - \frac{2p^2}{3} t + \frac{p^3}{9}
]

## ③ 展开 q 的部分

[
q(t - \frac{p}{3})
= qt - \frac{pq}{3}
]

---

# ⭐ 第 4 步：把所有展开项加起来

[
\text{把所有 }t^3,t^2,t,常数\text{分组}
]

---

## ✓ t³ 项：

只有：

[
t^3
]

---

## ✓ t² 项：

来自：

* 第一部分：(-p t^2)
* 第二部分：(p t^2)

二者相加：

[
-p t^2 + p t^2 = 0
]

👍 **二次项确实被消掉了！**

---

## ✓ t 项：

来自：

* 第一部分：(t \frac{p^2}{3})
* 第二部分：(-\frac{2p^2}{3} t)
* 第三部分：(qt)

加起来：

[
t\left(\frac{p^2}{3} - \frac{2p^2}{3} + q\right)
= t\left( q - \frac{p^2}{3} \right)
]

定义：

[
A = q - \frac{p^2}{3}
]

---

## ✓ 常数项：

来自：

* 第一部分：(-\frac{p^3}{27})
* 第二部分：(\frac{p^3}{9})
* 第三部分：(-\frac{pq}{3})
* 第四部分：(r)

将 (\frac{p^3}{9}) 化为 (\frac{3p^3}{27})：

[
-\frac{p^3}{27} + \frac{3p^3}{27}
= \frac{2p^3}{27}
]

所以全部常数项：

[
B = \frac{2p^3}{27} - \frac{pq}{3} + r
]

---

# ⭐ 第 5 步：得到“降次三次方程”

整理后得到：

[
t^3 + At + B = 0
]

其中：

[
A = q - \frac{p^2}{3}
]
[
B = \frac{2p^3}{27} - \frac{pq}{3} + r
]

---

# ⭐ 第 6 步：引入代换（核心技巧）

令：

[
t = u + v
]

代入：

[
(u+v)^3 + A(u+v) + B = 0
]

展开每项：

[
u^3 + v^3 + 3uv(u+v) + A(u+v) + B = 0
]

因为 (u+v = t)，替换回去：

[
u^3 + v^3 + (3uv + A)t + B = 0
]

但 t = u+v，所以：

[
u^3 + v^3 + (3uv + A)(u+v) + B = 0
]

为了让方程可解，我们让：

[
3uv + A = 0
]

于是：

[
uv = -\frac{A}{3}
]

方程简化为：

[
u^3 + v^3 + B = 0
]

设：

[
U = u^3, \quad V = v^3
]

则：

[
U + V = -B
]

并且：

[
uv = -\frac{A}{3}
\implies u^3 v^3 = \left(-\frac{A}{3}\right)^3
]
[
UV = -\left(\frac{A}{3}\right)^3
]

现在我们有：

[
\begin{cases}
U + V = -B \
UV = -\left(\frac{A}{3}\right)^3
\end{cases}
]

这是一个 **关于 U,V 的二元二次方程**！

---

# ⭐ 第 7 步：求 U,V

解：

[
z^2 + Bz - \left(\frac{A}{3}\right)^3 = 0
]

判别式：

[
\Delta = \left(\frac{B}{2}\right)^2 + \left(\frac{A}{3}\right)^3
]

两个根为：

[
U = -\frac{B}{2} + \sqrt{\Delta}
]
[
V = -\frac{B}{2} - \sqrt{\Delta}
]

---

# ⭐ 第 8 步：回到 u,v

[
u = \sqrt[3]{U}, \quad v = \sqrt[3]{V}
]

---

# ⭐ 第 9 步：得到 t

[
t = u + v
]

---

# ⭐ 第 10 步：还原回 x

记得最开始：

[
x = t - \frac{p}{3}
]

---

# 🎉 最终的 **卡尔达诺公式**

[
x = \sqrt[3]{-\frac{B}{2} + \sqrt{\Delta}}

* \sqrt[3]{-\frac{B}{2} - \sqrt{\Delta}}

- \frac{p}{3}
  ]

其中：

[
\Delta = \left(\frac{B}{2}\right)^2 + \left(\frac{A}{3}\right)^3
]

[
A = q - \frac{p^2}{3}
]
[
B = \frac{2p^3}{27} - \frac{pq}{3} + r
]

这就是完整的 Cardano 公式推导过程，**每一步都详列出来了**。
