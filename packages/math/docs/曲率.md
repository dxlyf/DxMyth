### 曲率的定义

曲率是描述曲线弯曲程度的量。在二维平面上，对于参数化曲线 \( \mathbf{r}(t) = (x(t), y(t)) \)，曲率 \( \kappa \) 的公式为：

\[
\kappa = \frac{|x'(t) y''(t) - y'(t) x''(t)|}{\left( x'(t)^2 + y'(t)^2 \right)^{3/2}}
\]

其中：
- \( x'(t) \) 和 \( y'(t) \) 是曲线的一阶导数。
- \( x''(t) \) 和 \( y''(t) \) 是曲线的二阶导数。

---

### 二次贝塞尔曲线的曲率

#### 二次贝塞尔曲线定义：
\[
\mathbf{B}(t) = (1-t)^2 \mathbf{P}_1 + 2t(1-t) \mathbf{P}_2 + t^2 \mathbf{P}_3
\]

其中：
- \( \mathbf{P}_1, \mathbf{P}_2, \mathbf{P}_3 \) 是控制点。
- \( t \in [0, 1] \) 是参数。

#### 一阶导数：
\[
\mathbf{B}'(t) = 2(1-t)(\mathbf{P}_2 - \mathbf{P}_1) + 2t(\mathbf{P}_3 - \mathbf{P}_2)
\]

#### 二阶导数：
\[
\mathbf{B}''(t) = 2(\mathbf{P}_3 - 2\mathbf{P}_2 + \mathbf{P}_1)
\]

#### 曲率公式：
将一阶导数和二阶导数代入曲率公式：
\[
\kappa = \frac{|B'_x(t) B''_y(t) - B'_y(t) B''_x(t)|}{\left( B'_x(t)^2 + B'_y(t)^2 \right)^{3/2}}
\]

---

### 三次贝塞尔曲线的曲率

#### 三次贝塞尔曲线定义：
\[
\mathbf{B}(t) = (1-t)^3 \mathbf{P}_1 + 3t(1-t)^2 \mathbf{P}_2 + 3t^2(1-t) \mathbf{P}_3 + t^3 \mathbf{P}_4
\]

#### 一阶导数：
\[
\mathbf{B}'(t) = 3(1-t)^2 (\mathbf{P}_2 - \mathbf{P}_1) + 6t(1-t)(\mathbf{P}_3 - \mathbf{P}_2) + 3t^2 (\mathbf{P}_4 - \mathbf{P}_3)
\]

#### 二阶导数：
\[
\mathbf{B}''(t) = 6(1-t)(\mathbf{P}_3 - 2\mathbf{P}_2 + \mathbf{P}_1) + 6t(\mathbf{P}_4 - 2\mathbf{P}_3 + \mathbf{P}_2)
\]

#### 曲率公式：
同样代入曲率公式：
\[
\kappa = \frac{|B'_x(t) B''_y(t) - B'_y(t) B''_x(t)|}{\left( B'_x(t)^2 + B'_y(t)^2 \right)^{3/2}}
\]

---

### 用 JavaScript 实现曲率计算

#### 二次贝塞尔曲线曲率：
```javascript
function quadraticBezierCurvature(p1, p2, p3, t) {
    // 控制点
    const [x1, y1] = p1;
    const [x2, y2] = p2;
    const [x3, y3] = p3;

    // 一阶导数
    const dx = 2 * (1 - t) * (x2 - x1) + 2 * t * (x3 - x2);
    const dy = 2 * (1 - t) * (y2 - y1) + 2 * t * (y3 - y2);

    // 二阶导数
    const ddx = 2 * (x3 - 2 * x2 + x1);
    const ddy = 2 * (y3 - 2 * y2 + y1);

    // 曲率
    const numerator = Math.abs(dx * ddy - dy * ddx);
    const denominator = Math.pow(dx * dx + dy * dy, 1.5);

    return numerator / denominator;
}
```

#### 三次贝塞尔曲线曲率：
```javascript
function cubicBezierCurvature(p1, p2, p3, p4, t) {
    // 控制点
    const [x1, y1] = p1;
    const [x2, y2] = p2;
    const [x3, y3] = p3;
    const [x4, y4] = p4;

    // 一阶导数
    const dx = 3 * (1 - t) ** 2 * (x2 - x1) +
               6 * (1 - t) * t * (x3 - x2) +
               3 * t ** 2 * (x4 - x3);

    const dy = 3 * (1 - t) ** 2 * (y2 - y1) +
               6 * (1 - t) * t * (y3 - y2) +
               3 * t ** 2 * (y4 - y3);

    // 二阶导数
    const ddx = 6 * (1 - t) * (x3 - 2 * x2 + x1) +
                6 * t * (x4 - 2 * x3 + x2);

    const ddy = 6 * (1 - t) * (y3 - 2 * y2 + y1) +
                6 * t * (y4 - 2 * y3 + y2);

    // 曲率
    const numerator = Math.abs(dx * ddy - dy * ddx);
    const denominator = Math.pow(dx * dx + dy * dy, 1.5);

    return numerator / denominator;
}
```

function binomialCoefficient(n, k) {
  let result = 1;
  for (let i = 1; i <= k; i++) {
    result *= (n + 1 - i) / i;
  }
  return result;
}

// 计算N阶贝塞尔曲线的一阶导数
function bezierFirstDerivative(controlPoints, t) {
  const n = controlPoints.length - 1;
  const derivative = [0, 0];

  for (let i = 0; i < n; i++) {
    const binom = binomialCoefficient(n - 1, i);
    const term = binom * Math.pow(1 - t, n - 1 - i) * Math.pow(t, i);
    derivative[0] += n * term * (controlPoints[i + 1][0] - controlPoints[i][0]);
    derivative[1] += n * term * (controlPoints[i + 1][1] - controlPoints[i][1]);
  }

  return derivative;
}

// 计算N阶贝塞尔曲线的二阶导数
function bezierSecondDerivative(controlPoints, t) {
  const n = controlPoints.length - 1;
  const secondDerivative = [0, 0];

  for (let i = 0; i < n - 1; i++) {
    const binom = binomialCoefficient(n - 2, i);
    const term = binom * Math.pow(1 - t, n - 2 - i) * Math.pow(t, i);
    secondDerivative[0] += n * (n - 1) * term * (controlPoints[i + 2][0] - 2 * controlPoints[i + 1][0] + controlPoints[i][0]);
    secondDerivative[1] += n * (n - 1) * term * (controlPoints[i + 2][1] - 2 * controlPoints[i + 1][1] + controlPoints[i][1]);
  }

  return secondDerivative;
}

要计算二阶和三阶贝塞尔曲线的曲率，我们需要使用导数和叉积来推导曲率公式。以下是详细的步骤和代码实现：

### 曲率公式
曲率 \( \kappa \) 表示曲线的弯曲程度，计算公式为：
\[
\kappa = \frac{| \mathbf{B}'(t) \times \mathbf{B}''(t) |}{|\mathbf{B}'(t)|^3}
\]
其中，\( \mathbf{B}'(t) \) 和 \( \mathbf{B}''(t) \) 分别是曲线的一阶和二阶导数，\( \times \) 表示向量叉积。

---

### 二阶贝塞尔曲线（二次）

#### 参数方程
控制点 \( P_0, P_1, P_2 \)，参数方程：
\[
\mathbf{B}(t) = (1-t)^2 P_0 + 2t(1-t) P_1 + t^2 P_2
\]

#### 导数推导
1. **一阶导数**：
\[
\mathbf{B}'(t) = 2 \left[ (1-t)(P_1 - P_0) + t(P_2 - P_1) \right]
\]
2. **二阶导数**（常数）：
\[
\mathbf{B}''(t) = 2 (P_0 - 2P_1 + P_2)
\]

#### 曲率计算代码
```javascript
function curvatureQuadratic(t, P0, P1, P2) {
    // 一阶导数
    const d1x = 2 * ((1 - t) * (P1.x - P0.x) + t * (P2.x - P1.x));
    const d1y = 2 * ((1 - t) * (P1.y - P0.y) + t * (P2.y - P1.y));
    
    // 二阶导数（常数）
    const d2x = 2 * (P0.x - 2 * P1.x + P2.x);
    const d2y = 2 * (P0.y - 2 * P1.y + P2.y);
    
    // 叉积和模长
    const cross = d1x * d2y - d1y * d2x;
    const d1Mag = Math.hypot(d1x, d1y);
    
    return d1Mag === 0 ? Infinity : Math.abs(cross) / Math.pow(d1Mag, 3);
}
```

---

### 三阶贝塞尔曲线（三次）

#### 参数方程
控制点 \( P_0, P_1, P_2, P_3 \)，参数方程：
\[
\mathbf{B}(t) = (1-t)^3 P_0 + 3t(1-t)^2 P_1 + 3t^2(1-t) P_2 + t^3 P_3
\]

#### 导数推导
1. **一阶导数**（二次贝塞尔曲线）：
\[
\mathbf{B}'(t) = 3 \left[ (1-t)^2 (P_1 - P_0) + 2t(1-t)(P_2 - P_1) + t^2 (P_3 - P_2) \right]
\]
2. **二阶导数**（线性贝塞尔曲线）：
\[
\mathbf{B}''(t) = 6 \left[ (1-t)(P_0 - 2P_1 + P_2) + t(P_1 - 2P_2 + P_3) \right]
\]

#### 曲率计算代码
```javascript
function curvatureCubic(t, P0, P1, P2, P3) {
    const u = 1 - t;
    
    // 一阶导数
    const d1x = 3 * (u*u*(P1.x - P0.x) + 2*u*t*(P2.x - P1.x) + t*t*(P3.x - P2.x));
    const d1y = 3 * (u*u*(P1.y - P0.y) + 2*u*t*(P2.y - P1.y) + t*t*(P3.y - P2.y));
    
    // 二阶导数
    const term1x = P0.x - 2*P1.x + P2.x;
    const term1y = P0.y - 2*P1.y + P2.y;
    const term2x = P1.x - 2*P2.x + P3.x;
    const term2y = P1.y - 2*P2.y + P3.y;
    const d2x = 6 * (term1x * u + term2x * t);
    const d2y = 6 * (term1y * u + term2y * t);
    
    // 叉积和模长
    const cross = d1x * d2y - d1y * d2x;
    const d1Mag = Math.hypot(d1x, d1y);
    
    return d1Mag === 0 ? Infinity : Math.abs(cross) / Math.pow(d1Mag, 3);
}
```

---

### 导数常用公式
- **n阶贝塞尔曲线的导数**：导数为 (n-1) 阶贝塞尔曲线，控制点为 \( n(P_{i+1} - P_i) \)。
- **二阶导数**：对一阶导数再次求导，得到 (n-2) 阶贝塞尔曲线。

### 关键点
- **叉积计算**：二维向量叉积结果为标量 \( d1x \cdot d2y - d1y \cdot d2x \)。
- **分母处理**：当一阶导数为零时，曲率无穷大（直线段除外）。

### **导数的推导过程**
贝塞尔曲线的参数方程为：
\[
\mathbf{B}(t) = \sum_{i=0}^n \binom{n}{i} t^i (1-t)^{n-i} P_i

其中 \( n \) 为曲线阶数，\( P_i \) 是控制点。

#### **一阶导数**
一阶导数 \( \mathbf{B}'(t) \) 是 \( (n-1) \) 阶贝塞尔曲线，控制点为：
\[
\mathbf{D}_i^{(1)} = n \cdot (P_{i+1} - P_i) \quad (0 \leq i \leq n-1)
\]

#### **二阶导数**
二阶导数 \( \mathbf{B}''(t) \) 是 \( (n-2) \) 阶贝塞尔曲线，控制点为：
\[
\mathbf{D}_i^{(2)} = n(n-1) \cdot (P_{i+2} - 2P_{i+1} + P_i) \quad (0 \leq i \leq n-2)
\]

#### 1. **计算一阶导数控制点**
```javascript
function computeFirstDerivativeControlPoints(points) {
  const n = points.length - 1;
  if (n < 1) throw new Error("需要至少2个控制点");
  const dPoints = [];
  for (let i = 0; i < n; i++) {
    const dx = n * (points[i + 1].x - points[i].x);
    const dy = n * (points[i + 1].y - points[i].y);
    dPoints.push({ x: dx, y: dy });
  }
  return dPoints;
}
```

#### 2. **计算二阶导数控制点**
```javascript
function computeSecondDerivativeControlPoints(points) {
  const n = points.length - 1;
  if (n < 2) throw new Error("需要至少3个控制点");
  const ddPoints = [];
  const factor = n * (n - 1);
  for (let i = 0; i <= n - 2; i++) {
    const dx = factor * (points[i + 2].x - 2 * points[i + 1].x + points[i].x);
    const dy = factor * (points[i + 2].y - 2 * points[i + 1].y + points[i].y);
    ddPoints.push({ x: dx, y: dy });
  }
  return ddPoints;
}
```

#### 3. **通用贝塞尔曲线求值函数（De Casteljau算法）**
```javascript
function evaluateBezier(t, points) {
  let currentPoints = [...points];
  while (currentPoints.length > 1) {
    const newPoints = [];
    for (let i = 0; i < currentPoints.length - 1; i++) {
      const x = (1 - t) * currentPoints[i].x + t * currentPoints[i + 1].x;
      const y = (1 - t) * currentPoints[i].y + t * currentPoints[i + 1].y;
      newPoints.push({ x, y });
    }
    currentPoints = newPoints;
  }
  return currentPoints[0];
}
```

#### 4. **计算一阶和二阶导数在 \( t \) 处的值**
```javascript
function getFirstDerivative(t, points) {
  const dPoints = computeFirstDerivativeControlPoints(points);
  return evaluateBezier(t, dPoints);
}

function getSecondDerivative(t, points) {
  const ddPoints = computeSecondDerivativeControlPoints(points);
  return evaluateBezier(t, ddPoints);
}
```

二阶导数 \( \mathbf{B}''(t) \) 是 **N-2阶贝塞尔曲线**，控制点为：
\[
\mathbf{D}_i^{(2)} = n(n-1) \cdot (P_{i+2} - 2P_{i+1} + P_i) \quad (0 \leq i \leq n-2)
\]

### **四、关键解释**
1. **一阶导数**：
   - 控制点由相邻点差值乘以阶数 \( n \) 得到。
   - 例如：四阶曲线（5个控制点）的一阶导数是三阶曲线（4个控制点）。

2. **二阶导数**：
   - 对一阶导数控制点再次应用差分，并乘以 \( n(n-1) \)。
   - 例如：四阶曲线的二阶导数是二阶曲线（3个控制点）。

3. **De Casteljau算法**：
   - 通过递归线性插值计算任意 \( t \) 处的值，适用于任意阶贝塞尔曲线。
