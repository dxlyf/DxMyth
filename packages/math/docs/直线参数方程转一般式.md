## **1. 直线方程的种类**
直线的方程有多种表示方式，主要包括：

| **方程类型** | **形式** | **适用范围** |
|-------------|----------|-------------|
| **一般式** | \( Ax + By + C = 0 \) | 适用于所有直线（包括垂直、水平、斜线） |
| **斜截式** | \( y = kx + b \) | 适用于非垂直直线（即 \( A \neq 0, B \neq 0 \)） |
| **点斜式** | \( y - y_1 = k(x - x_1) \) | 适用于非垂直直线，已知直线上一点 \( (x_1, y_1) \) 和斜率 \( k \) |
| **两点式** | \( y - y_1 = \frac{y_2 - y_1}{x_2 - x_1} (x - x_1) \) | 适用于非垂直直线，已知直线上两点 \( (x_1, y_1) \)、\( (x_2, y_2) \) |
| **点法式（点向式）** | \( \frac{x - x_0}{a} = \frac{y - y_0}{b} \) | 适用于所有直线，已知直线上一点 \( (x_0, y_0) \) 和方向向量 \( (a, b) \) |
| **参数式** | \( x = x_0 + at, \quad y = y_0 + bt \) | 适用于所有直线，已知直线上一点 \( (x_0, y_0) \) 和方向向量 \( (a, b) \) |
| **极坐标式** | \( r = \frac{p}{\cos(\theta - \alpha)} \) | 适用于极坐标系中，\( p \) 是极径，\( \alpha \) 是极角 |

---

## **2. 各种直线方程转换为一般式**
一般式方程的标准形式为：
\[
Ax + By + C = 0
\]
其中，\( A, B, C \) 为常数，且 \( A \) 和 \( B \) 不同时为零。

### **(1) 斜截式 → 一般式**
斜截式：
\[
y = kx + b
\]
移项：
\[
-kx + y - b = 0
\]
整理为：
\[
kx - y + b = 0
\]
即 \( A = k, B = -1, C = b \)。

---

### **(2) 点斜式 → 一般式**
点斜式：
\[
y - y_1 = k(x - x_1)
\]
展开：
\[
y - y_1 = kx - kx_1
\]
移项：
\[
kx - y + (y_1 - kx_1) = 0
\]
即 \( A = k, B = -1, C = y_1 - kx_1 \)。

---

### **(3) 两点式 → 一般式**
两点式：
\[
y - y_1 = \frac{y_2 - y_1}{x_2 - x_1} (x - x_1)
\]
设 \( k = \frac{y_2 - y_1}{x_2 - x_1} \)，则：
\[
y - y_1 = kx - kx_1
\]
整理：
\[
kx - y + (y_1 - kx_1) = 0
\]

或直接交叉相乘：
\[
(y - y_1)(x_2 - x_1) = (x - x_1)(y_2 - y_1)
\]
展开：
\[
yx_2 - yx_1 - y_1x_2 + y_1x_1 = xy_2 - xy_1 - x_1y_2 + x_1y_1
\]
整理：
\[
(x_2 - x_1)y - (y_2 - y_1)x + (y_1x_2 - x_1y_2) = 0
\]
即：
\[
A = (y_2 - y_1), \quad B = -(x_2 - x_1), \quad C = (y_1x_2 - x_1y_2)
\]

---

### **(4) 点法式（点向式） → 一般式**
点向式：
\[
\frac{x - x_0}{a} = \frac{y - y_0}{b}
\]
交叉相乘：
\[
b(x - x_0) = a(y - y_0)
\]
展开：
\[
bx - bx_0 = ay - ay_0
\]
整理：
\[
bx - ay + (ay_0 - bx_0) = 0
\]

---

### **(5) 参数式 → 一般式**
参数方程：
\[
x = x_0 + at, \quad y = y_0 + bt
\]
消去 \( t \)：
\[
\frac{x - x_0}{a} = \frac{y - y_0}{b}
\]
交叉相乘：
\[
b(x - x_0) = a(y - y_0)
\]
展开：
\[
bx - ay + (ay_0 - bx_0) = 0
\]
即 \( A = b, B = -a, C = ay_0 - bx_0 \)。

---

## **3. 解直线方程组**
求两条直线的交点，即求方程组：
\[
A_1x + B_1y + C_1 = 0
\]
\[
A_2x + B_2y + C_2 = 0
\]

### **(1) 行列式法（克莱姆法则）**
如果：
\[
D =
\begin{vmatrix}
A_1 & B_1 \\
A_2 & B_2
\end{vmatrix}
= A_1B_2 - A_2B_1 \neq 0
\]

则解为：

\[x =
\frac{
\begin{vmatrix}
-C_1 & B_1 \\
-C_2 & B_2
\end{vmatrix}
}{D}=\frac{B_1C_2 - B_2C_1}{A_1B_2 - A_2B_1}
\]

\[
y =
\frac{
\begin{vmatrix}
A_1 & -C_1 \\
A_2 & -C_2
\end{vmatrix}
}{D}=\frac{C_1A_2 - C_2A_1}{A_1B_2 - A_2B_1}
\]

### **(2) 代入法**
1. 解出 \( y \)：
   \[
   y = \frac{-A_1x - C_1}{B_1}
   \]
2. 代入另一条直线：
   \[
   A_2x + B_2 \left(\frac{-A_1x - C_1}{B_1} \right) + C_2 = 0
   \]
3. 解出 \( x \)，再代入求 \( y \)。

1. 直线方程有**一般式、斜截式、点斜式、两点式、点向式、参数式等**。
2. **转换一般式**的方法可以通过消去参数或移项整理。
3. **求交点**可以用**克莱姆法则**或**代入法**。

其中：

### **转换为一般式**
直线的一般式方程为：

\[
Ax + By + C = 0
\]

#### **推导过程**
1. 由参数方程消去 \( t \)：
   - \( x - x_0 = at \)
   - \( y - y_0 = bt \)
   - 消去 \( t \)：
     \[
     \frac{x - x_0}{a} = \frac{y - y_0}{b}
     \]
     交叉相乘：
     \[
     b(x - x_0) = a(y - y_0)
     \]

2. 整理成一般式：
   \[
   bx - ay + (ay_0 - bx_0) = 0
   \]

   令：
   \[
   A = b, \quad B = -a, \quad C = ay_0 - bx_0
   \]

   得到：
   \[
   A x + B y + C = 0
   \]

\]

\[
-4(x - 2) = 3(y - 1)
\]

展开：
\[
-4x + 8 = 3y - 3
\]

整理：
\[
4x + 3y - 11 = 0
\]

即为一般式方程。



给定直线上的一个点 \( P_0 = (x_0, y_0) \) 和方向向量 \( \vec{v} = (a, b) \)，我们可以求出该直线的 **x-截距** 和 **y-截距**。

### **步骤 1：求直线的参数方程**
直线的参数方程可以表示为：
\[
\begin{cases}
x = x_0 + a t \\
y = y_0 + b t
\end{cases}
\]
其中 \( t \) 是参数。

### **步骤 2：求 x-截距（与 x 轴的交点）**
x-截距是直线与 x 轴的交点，此时 \( y = 0 \)。

设 \( y = 0 \)，代入参数方程：
\[
0 = y_0 + b t \implies t = -\frac{y_0}{b}
\]

再代入 \( x = x_0 + a t \)：
\[
x = x_0 + a \left( -\frac{y_0}{b} \right) = x_0 - \frac{a y_0}{b}
\]

因此，x-截距为：
\[
\left( x_0 - \frac{a y_0}{b}, 0 \right)
\]
**x-截距值**（即 \( x \) 坐标）为：
\[
x_{\text{intercept}} = x_0 - \frac{a y_0}{b}
\]

### **步骤 3：求 y-截距（与 y 轴的交点）**
y-截距是直线与 y 轴的交点，此时 \( x = 0 \)。

设 \( x = 0 \)，代入参数方程：
\[
0 = x_0 + a t \implies t = -\frac{x_0}{a}
\]

再代入 \( y = y_0 + b t \)：
\[
y = y_0 + b \left( -\frac{x_0}{a} \right) = y_0 - \frac{b x_0}{a}
\]

因此，y-截距为：
\[
\left( 0, y_0 - \frac{b x_0}{a} \right)
\]
**y-截距值**（即 \( y \) 坐标）为：
\[
y_{\text{intercept}} = y_0 - \frac{b x_0}{a}
\]

### **特殊情况处理**
1. **如果方向向量平行于 x 轴（即 \( b = 0 \)）**：
   - 直线是水平的，没有 **x-截距**（除非 \( y_0 = 0 \)，此时直线本身就是 x 轴）。
   - y-截距为 \( (0, y_0) \)。

2. **如果方向向量平行于 y 轴（即 \( a = 0 \)）**：
   - 直线是垂直的，没有 **y-截距**（除非 \( x_0 = 0 \)，此时直线本身就是 y 轴）。
   - x-截距为 \( (x_0, 0) \)。

### **最终公式**
| 截距类型 | 公式 |
|----------|------|
| **x-截距** | \( x_0 - \frac{a y_0}{b} \) |
| **y-截距** | \( y_0 - \frac{b x_0}{a} \) |

### **示例**
**给定**：
- 点 \( P_0 = (2, 3) \)
- 方向向量 \( \vec{v} = (1, -2) \)

**计算**：
1. **x-截距**：
   \[
   x_{\text{intercept}} = 2 - \frac{1 \times 3}{-2} = 2 + \frac{3}{2} = \frac{7}{2}
   \]
   → 截距点 \( \left( \frac{7}{2}, 0 \right) \)

2. **y-截距**：
   \[
   y_{\text{intercept}} = 3 - \frac{(-2) \times 2}{1} = 3 + 4 = 7
   \]
   → 截距点 \( (0, 7) \)

### **结论**
- **x-截距**：\( x_0 - \frac{a y_0}{b} \)
- **y-截距**：\( y_0 - \frac{b x_0}{a} \)

如果分母为零（即 \( a = 0 \) 或 \( b = 0 \)），则直线平行于坐标轴，其中一个截距不存在。

### **问题描述**
设圆的中心点为 \( O \)，圆上的点为 \( P \)，\( L \) 是 \( (P.x, O.y) \)，即 \( L \) 是 \( P \) 在水平方向上的投影点（保持 \( y \) 坐标与 \( O \) 相同）。这样，\( \triangle POL \) 是一个直角三角形，其中：
- \( \angle OLP = 90^\circ \)
- \( \angle POL \) 是我们关注的角。

### **1. 计算 \( \cos \theta \)、\( \sin \theta \)、\( \tan \theta \)**
设圆的半径为 \( r \)，则：
- \( OP = r \)（圆的半径）
- \( OL = P.x - O.x \)
- \( PL = P.y - O.y \)

在 \( \triangle POL \) 中：
- **斜边** \( OP = r \)
- **邻边**（相对于 \( \angle POL \)）\( OL = P.x - O.x \)
- **对边** \( PL = P.y - O.y \)

因此：
\[
\cos \theta = \frac{OL}{OP} = \frac{P.x - O.x}{r}
\]
\[
\sin \theta = \frac{PL}{OP} = \frac{P.y - O.y}{r}
\]
\[
\tan \theta = \frac{PL}{OL} = \frac{P.y - O.y}{P.x - O.x}
\]

#### **几何意义**
- \( \cos \theta \) 表示 \( P \) 的 **x 坐标偏移量**（相对于圆心）与半径的比值。
- \( \sin \theta \) 表示 \( P \) 的 **y 坐标偏移量**（相对于圆心）与半径的比值。
- \( \tan \theta \) 表示 \( P \) 的 **y 变化量 / x 变化量**，即 **斜率**。

### **2. \( \tan \theta \) 与 \( P \) 点切线的斜率的关系**
圆的方程：
\[
(x - O.x)^2 + (y - O.y)^2 = r^2
\]
对 \( x \) 求导（隐函数求导）：
\[
2(x - O.x) + 2(y - O.y) \frac{dy}{dx} = 0
\]
解得：
\[
\frac{dy}{dx} = -\frac{x - O.x}{y - O.y}
\]
因此，**切线的斜率** \( m_{\text{tangent}} \) 为：
\[
m_{\text{tangent}} = -\frac{OL}{PL} = -\frac{P.x - O.x}{P.y - O.y}
\]

而 \( \tan \theta = \frac{PL}{OL} \)，所以：
\[
m_{\text{tangent}} = -\frac{1}{\tan \theta}
\]

#### **结论**
- **切线的斜率** 是 \( \tan \theta \) 的 **负倒数**。
- 这意味着 **切线与半径 \( OP \) 垂直**（因为两条直线的斜率乘积为 \( -1 \)）。

### **3. 几何直观**
- \( \theta \) 是半径 \( OP \) 与水平方向的夹角。
- **切线** 是垂直于 \( OP \) 的直线，因此它的斜率是 \( \tan \theta \) 的负倒数。
- 如果 \( \theta \) 增大（\( P \) 沿逆时针方向移动），切线斜率会相应变化。

##  **点到直线的距离**

### ✅ 一、标准公式（解析几何法）

#### 当直线为一般式 $Ax + By + C = 0$，点为 $P(x_0, y_0)$

$$
\text{距离} = \frac{|Ax_0 + By_0 + C|}{\sqrt{A^2 + B^2}}
$$

* ✅ **优点**：通用、精确
* ❗**注意**：需要直线是一般式

---

### ✅ 二、向量法（适用于直线由两个点定义）

设直线由两点 $A(x_1, y_1)$、$B(x_2, y_2)$ 定义，目标点为 $P(x_0, y_0)$。

#### 公式：

$$
\text{距离} = \frac{|(x_2 - x_1)(y_1 - y_0) - (x_1 - x_0)(y_2 - y_1)|}{\sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}}
$$

* ✅ **原理**：分子是向量叉积（面积），分母是 AB 向量模长
* ✅ **适用**：只知道两个点，无需显式方程
* ✅ **适用于3D**：方法类似，但用向量投影+叉积计算垂距

---

### ✅ 三、投影法（常用于计算点到线段的最短距离）

设直线起点为 $A$、终点为 $B$，目标点为 $P$，则：

#### 步骤：

1. 定义向量：

   * $\vec{AB} = B - A$
   * $\vec{AP} = P - A$
2. 投影参数：

   $$
   t = \frac{\vec{AB} \cdot \vec{AP}}{|\vec{AB}|^2}
   $$
3. 得到投影点 $Q = A + t \cdot \vec{AB}$
4. 距离即为 $|P - Q|$

* 🟡 若 $t < 0$ 表示最近点是 A
* 🟡 若 $t > 1$ 表示最近点是 B
* 🟢 若 $0 \leq t \leq 1$，说明投影落在线段上

---

### ✅ 四、三维点到直线距离（向量法扩展）

设点为 $P$，直线为经过点 $A$ 且方向向量为 $\vec{v}$，则：

$$
\text{距离} = \frac{|\vec{AP} \times \vec{v}|}{|\vec{v}|}
$$

---

### ✅ 五、JavaScript 实现（向量法示例）

```js
function pointToLineDistance(px, py, x1, y1, x2, y2) {
  const dx = x2 - x1;
  const dy = y2 - y1;
  const numerator = Math.abs(dx * (y1 - py) - (x1 - px) * dy);
  const denominator = Math.hypot(dx, dy);
  return numerator / denominator;
}
```

| 方法    | 优点               | 缺点      | 适用场景         |
| ----- | ---------------- | ------- | ------------ |
| 一般式公式 | 简洁直接             | 需方程已知   | 一般形式直线       |
| 向量法   | 无需转换为方程，易实现      | 仅适用于二维  | 两点定义直线       |
| 投影法   | 可用于“点到线段”的最近距离计算 | 实现稍复杂   | 距离、最近点、碰撞判断等 |
