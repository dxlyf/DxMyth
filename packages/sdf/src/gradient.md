Canvas 三种渐变——**线性渐变**、**径向渐变**、**锥形渐变**——底层原理都建立在一个统一的模型上：  
将每一个像素映射到一个标量参数 `t`（通常归一到 `[0,1]`），再通过 `t` 在一组**颜色停止点**之间做插值得到最终颜色。差异只在于如何从像素坐标计算出这个 `t`。

下面从通用基础开始，再逐一剖析三种渐变的几何映射、颜色插值和渲染流程。

---

## 1. 通用基础：颜色映射与插值原理

### 1.1 颜色停止点（Color Stop）
每个渐变持有一个有序的停止点列表 `(offset, color)`，`offset ∈ [0,1]`。  
渲染时，对于当前像素计算出的参数 `t`，会找到它前后两个停止点，执行线性插值。

### 1.2 预乘 Alpha 的 sRGB 插值（关键）
Canvas 规范要求颜色插值在**预乘 alpha** 的 sRGB 空间进行，流程如下：

1. 对每个停止点的颜色 `(R, G, B, A)` 计算预乘值：  
   `R' = R × A`, `G' = G × A`, `B' = B × A`，`A` 保持不变。
2. 在 `t` 处对 `R'`、`G'`、`B'`、`A` 四个通道**分别线性插值**，得到插值后的预乘结果 `(R'_t, G'_t, B'_t, A_t)`。
3. 若 `A_t > 0`，最终像素颜色为：  
   `(R'_t / A_t, G'_t / A_t, B'_t / A_t, A_t)`；  
   若 `A_t = 0`，则颜色为透明黑 `(0,0,0,0)`。

这样做的目的：避免在半透明过渡区出现不自然的黑边或色偏，保证透明度变化时视觉的平滑性。

### 1.3 扩展模式（Spread Method）
超出 `[0,1]` 范围的 `t` 如何处理？Canvas 2D 原生的渐变对象默认使用 **pad** 模式（即 clamp）：

- `t < 0` → 取第一个停止点的颜色
- `t > 1` → 取最后一个停止点的颜色
- 没有内置的 `repeat` 或 `reflect` 模式（与 CSS 的 `repeating-*-gradient` 不同）。

### 1.4 坐标变换的影响
渐变本身定义在**用户坐标系**中。执行 `fill()` / `stroke()` 时，每个像素会先通过**当前变换矩阵（CTM）的逆矩阵**映射回用户空间，再计算 `t`。  
因此缩放、旋转、平移画布会同时改变渐变效果，这等价于渐变“跟随”路径一起变换。

## 2. 线性渐变：正交投影到渐变线

### API 原型
```js
ctx.createLinearGradient(x0, y0, x1, y1)
```
定义了一条有向**渐变线**，起点 `P0(x0, y0)`，终点 `P1(x1, y1)`。

### 几何映射原理
对于任意像素点 `P(x, y)`（用户坐标），计算它在渐变线上的投影比例：

\[
t = \frac{(P - P_0) \cdot (P_1 - P_0)}{|P_1 - P_0|^2}
\]

- 若 `t = 0`，像素正好过 `P0` 的垂直平面；
- 若 `t = 1`，像素正好过 `P1` 的垂直平面；
- 其他位置线性延伸。

**直观理解**：以渐变线为轴，垂直于该轴的每条直线上所有点拥有相同的 `t`，即“等色线”是与渐变线垂直的平行线族。

### 边界处理
按照 pad 模式，`t < 0` 时固定为 0，`t > 1` 时固定为 1，形成两端纯色延伸。

### 底层着色器伪码（线性渐变）
```glsl
// 在用户坐标系中
vec2 gradVec = P1 - P0;
float t = dot(P - P0, gradVec) / dot(gradVec, gradVec);
t = clamp(t, 0.0, 1.0);
// 再根据 t 在 color stops 中插值得到颜色
```

## 3. 径向渐变：两个圆的参数化过渡

### API 原型
```js
ctx.createRadialGradient(x0, y0, r0, x1, y1, r1)
```
定义起始圆 `C0(圆心P0, 半径r0)` 和终点圆 `C1(圆心P1, 半径r1)`。渐变从 `C0` 的边缘（半径 r0）过渡到 `C1` 的边缘（半径 r1）。

### 几何映射原理
径向渐变本质上定义了一族**线性插值的圆**：  
圆心在 `P(t) = P0 + t·(P1 - P0)`，半径 `r(t) = r0 + t·(r1 - r0)`，`t ∈ [0,1]`。

对于任意像素点 `P`，需要找到一个 `t` 使得该点正好位于这条移动圆上，即满足：

\[
|P - P(t)| = r(t)
\]

展开分量形式（设 `dx = x1 - x0`, `dy = y1 - y0`, `dr = r1 - r0`）：

\[
(x - x0 - t·dx)^2 + (y - y0 - t·dy)^2 = (r0 + t·dr)^2
\]

整理得到一个关于 `t` 的**二次方程**：

\[
(dx^2 + dy^2 - dr^2)·t^2 + 2[dx·(x0 - x) + dy·(y0 - y) - r0·dr]·t + [(x - x0)^2 + (y - y0)^2 - r0^2] = 0
\]

### 求解与根的选择
- 若 `dx^2 + dy^2 - dr^2 ≠ 0`（非退化），解出两个根。
- 根据图形学惯例，应选择使得点位于渐变圆锥面上合适的 `t`。实际实现中，取**更靠近 `[0,1]` 的那个根**，然后 `clamp(t, 0, 1)`。
- 当两圆**同心**时，退化为一维距离插值：  
  设 `dist = |P - P0|`，则 `t = (dist - r0) / (r1 - r0)`。
- `r0 = r1` 且圆心不同时，退化为“线性”外推，底层仍然用上述二次方程。

### 实现注意
存在 `t` 在 `[0,1]` 之外仍能解出距离相等的情况（例如点在圆锥外扩展面上），此时 clamp 到 0 或 1 即形成 pad 效果，即第一个圆以内全部填充起始色，最后一个圆以外全部填充结束色。

> Skia、CoreGraphics 等底层库都使用这一二次方程求解策略。

## 4. 锥形渐变：角度扫描映射

### API 原型
```js
ctx.createConicGradient(startAngle, cx, cy)
```
围绕中心点 `C(cx, cy)` 旋转一圈产生渐变。

### 几何映射原理
对于像素 `P`，计算它相对于中心点的**角度**：

1. 使用 `atan2(y - cy, x - cx)` 得到弧度值 `θ`，范围 `[-π, π]`。
2. 旋转角度以适配起始角：`θ' = θ - startAngle`。
3. 将角度归一到 `[0, 2π)` 并映射到 `t ∈ [0,1)`：  
   `t = θ' / (2π)`，若 `θ' < 0` 则加 `2π`。

得到的 `t` 从 0 到 1 对应完整一圈。

**注意**：Canvas 的 `startAngle` 遵循与 `arc()` 相同的方向——0 弧度指向 **x 轴正方向（3 点钟方向）**，角度增加为**顺时针**。  
这与 CSS `conic-gradient()` 的 0° 在 12 点钟、顺时针增加的规则**不同**，需要注意转换。

### 边界处理
默认 pad 模式下，`t` 会被 clamp 在 `[0,1]` 之内，因此仅有一圈有效渐变，重复部分的颜色会被切断为端点色。  
若需要重复效果，只能手动构建多个色标或通过着色器模拟。

### 底层实现伪码（锥形）
```glsl
vec2 dir = P - C;
float angle = atan(dir.y, dir.x);  // 范围 (-π, π]
angle -= startAngle;
angle = mod(angle, 2*PI);
if (angle < 0.0) angle += 2*PI;
float t = angle / (2 * PI);
// pad: t = clamp(t, 0.0, 1.0);
```

## 5. 整体渲染流程

当执行 `ctx.fill()` 或 `ctx.stroke()` 且当前 `fillStyle`/`strokeStyle` 为渐变对象时，大致步骤如下：

1. **遍历图形像素**（通过扫描线、三角剖分或光栅化）。
2. **逆 CTM 变换**：将像素从设备坐标变换到用户坐标。
3. **根据渐变类型计算 `t`**：按上述线性、径向或锥形方法。
4. **颜色停止点查询**：用 `t` 找到相邻两个停止点。
5. **预乘插值**：在预乘 sRGB 空间线性插值，得到最终预乘色，再除以插值后 alpha 得到 RGBA。
6. **合成**：按 `globalCompositeOperation` 等规则与目标像素混合。

由于现代 2D 图形库（Skia / Direct2D / CoreGraphics）会将渐变编译为 GPU 着色器，上述计算实际发生在片段着色器（fragment shader）中，保证了每像素高效执行。

---

## 6. 总结对比

| 渐变类型 | 参数域 `t` 的计算方式 | 等值面形状 |
|----------|----------------------|----------------|
| 线性渐变 | 点到渐变线的正交投影比例 | 一组平行直线 |
| 径向渐变 | 求解“移动圆”的二次方程，找到使点到动态圆心距离等于动态半径的 t | 一组同心/偏心的圆（圆锥曲线） |
| 锥形渐变 | 点相对中心的角度归一化 | 一组放射状射线（扇形） |

三者都依赖同一条颜色插值管线，仅是空间参数化的公式不同。理解这些几何映射，不仅能准确预测渐变效果，也为手写着色器实现更复杂的渐变（如重复、多焦点）打下基础。
