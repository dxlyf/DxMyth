# LayerManager（图层管理 + 离屏 Surface 缓存）完整设计与实现方案

太好了——下面我会一步到位给出 **LayerManager 的完整设计、API、实现要点、代码片段、集成说明、注意事项与示例**。你拿到这些就能把 LayerManager 接入现有引擎（Engine / Renderer / PaintPool / PathPool）并在交互场景里显著减少重绘工作量。

---

# 一、目标与设计原则

**目标**

* 为场景树或子树提供可选的离屏缓存（CanvasKit.Surface），只在该子树发生变化（dirty）时重新绘制离屏 Surface，然后把离屏内容合成为主画布的一部分。
* 降低复杂交互场景（拖拽、动画）或静态 UI 层（背景、面板）的重复绘制开销。

**设计原则**

1. **可选按节点/子树启用**：不强制所有节点都使用 Layer；通过 `node.setLayer({mode:'auto'|'always'|'never'})` 控制。
2. **脏标记（dirty）驱动**：当子树发生变更（transform、样式、结构）时标记 Layer dirty。
3. **按 devicePixelRatio 缩放缓存**：保存离屏 Surface 的像素密度与主 canvas 一致。
4. **受限 Surface 大小**：离屏 surface 最大尺寸限制（例如 2048×2048），超限需切片或回退到非缓存绘制。
5. **合成优先级**：Layer 仍遵循 globalZ 排序（合成时按 z 绘制）保证视觉一致性。
6. **生命周期管理**：Engine 在 dispose 时释放所有 Layer 的 native handles。
7. **最小 API**：易用并暴露 debug 信息（cache hit/miss、size、lastDrawTime）。

# 三、API 设计（外部使用）

* `node.enableLayer(policy?: LayerPolicy)`：为 node（子树根）开启 Layer 缓存。
* `node.disableLayer()`：关闭 Layer。
* `engine.render()`：Renderer 会自动使用 LayerManager 合成已缓存 Layer。
* `engine.layerManager.debug()`：返回缓存统计（entries、hits、misses、memUsage）。

# 四、实现细节（核心逻辑）

流程概览：

1. 对场景树遍历（收集渲染队列）时，LayerManager 会把启用了 Layer 的节点（layerRoot）识别出来，**跳过**该子树的内部细化收集（因为它将由该 Layer 独立绘制）。
2. 对于每个 LayerEntry：

   * 如果 `dirty` 或 `surface` 不存在 → 在 layer 的离屏 surface 上重新渲染该子树（调用内部 renderer 对该子树进行绘制）并将 `dirty = false`。
   * 否则直接把 `surface` 的 image 绘制到主 canvas（compose）。
3. 合成时仍保持 `globalZ` 顺序：把 layer 视作一个单独的渲染单元（其 z = layerRoot.globalZ）。
4. 当 layerRoot 的子节点变更（`add/remove`/`setTransform`/`styleChange`等）时调用 `layer.markDirty()`。Engine 在默认的 `Node.add/remove/markDirty()` hook 内可以自动调用。

重要实现点：

* **离屏 Surface 创建**：`CanvasKit.MakeSurface(width, height)` 或 `MakeN32Canvas`（取决 CanvasKit 版本）。Surface 要与 DPR 成比例。
* **Surface 上限控制**：若 layer bounds 超过 `maxSurfaceWH`（例如 2048），需拆分为 tile 或直接退回到直接渲染（不缓存）。拆分实现复杂，此处先提供回退策略（不可缓存时直接逐帧绘制）。
* **内容裁剪与 padding**：Layer 绘制区域以 layerRoot 的包围盒（bounds）为基础，可留一点 padding 用于滤镜(blur)或阴影（shadow），防止裁切。
* **清理**：销毁 layer 时 `.surface.delete()` 并释放内部 CanvasKit.Image。
* **线程与 WASM 边界**：尽量在一个渲染循环内批量创建/释放 surface，避免大量跨界分配/销毁。

### `src/renderer/Layer.ts`

```ts
// Layer.ts
import type * as CanvasKitModule from 'canvaskit-wasm';
import { Node } from '../scene/Node';

export type LayerPolicy = {
  mode?: 'auto' | 'always' | 'never'; // auto: decide by heuristics, always: always cache, never: disable
  maxWidth?: number;
  maxHeight?: number;
  padding?: number; // padding pixels for shadows/filters
};

export class Layer {
  CanvasKit: any;
  root: Node; // layer root (subtree)
  policy: LayerPolicy;
  surface: any | null = null; // offscreen surface (CanvasKit.Surface)
  width = 0;
  height = 0;
  dirty = true;
  lastRenderedAt = 0;
  dpr = 1;
  cachedImage: any | null = null; // CanvasKit.Image snapshot (optional)
  debugName?: string;

  constructor(CanvasKit: any, root: Node, policy?: LayerPolicy) {
    this.CanvasKit = CanvasKit;
    this.root = root;
    this.policy = { mode: 'auto', maxWidth: 2048, maxHeight: 2048, padding: 2, ...(policy || {}) };
    this.dpr = 1;
    this.debugName = (root as any).name || 'layer';
  }

  markDirty() {
    this.dirty = true;
  }

  /** create or resize offscreen surface to match target pixel size */
  ensureSurface(targetW: number, targetH: number, dpr: number) {
    const ck = this.CanvasKit;
    const tw = Math.round(targetW * dpr);
    const th = Math.round(targetH * dpr);

    // if too big, return false -> cannot cache
    if (tw <= 0 || th <= 0) return false;
    if (this.policy.maxWidth && tw > this.policy.maxWidth) return false;
    if (this.policy.maxHeight && th > this.policy.maxHeight) return false;

    // recreate if size changed or surface not exist
    if (!this.surface || this.width !== tw || this.height !== th || this.dpr !== dpr) {
      // delete old
      try { this.surface?.dispose?.(); } catch (e) {}
      this.surface = ck.MakeCanvasSurface({width: tw, height: th} as any) || ck.MakeCanvasSurface && ck.MakeCanvasSurface(this._makeCanvasElement(tw, th)); 
      // Above is defensive: different CanvasKit versions have different creation APIs. 
      // Prefer ck.MakeCanvasSurface(canvasElem) in earlier implementations.
      // We'll fallback to a helper canvas element if needed.
      this.width = tw;
      this.height = th;
      this.dpr = dpr;
    }
    return !!this.surface;
  }

  // helper to create an HTMLCanvasElement to feed MakeCanvasSurface if needed
  private _makeCanvasElement(w: number, h: number) {
    const c = document.createElement('canvas');
    c.width = w;
    c.height = h;
    return c;
  }

  /** re-render subtree into offscreen surface */
  renderToSurface(renderFn: (root: Node, canvas:any, CanvasKit:any) => void, bounds: {x:number,y:number,w:number,h:number}, dpr:number) {
    if (!this.ensureSurface(bounds.w, bounds.h, dpr)) {
      // cannot cache => fallback
      this.dirty = true;
      return false;
    }
    // draw on offscreen
    const canvas = this.surface.getCanvas();
    // clear with transparent
    canvas.clear(this.CanvasKit.Color(0,0,0,0));

    canvas.save();
    // scale to dpr and translate so (0,0) maps to bounds.x/bounds.y
    canvas.scale(dpr, dpr);
    canvas.translate(-bounds.x, -bounds.y);

    // call provided render function to draw this.root into the offscreen canvas
    renderFn(this.root, canvas, this.CanvasKit);

    canvas.restore();
    this.surface.flush();

    // optionally snapshot to image (not necessary, can draw surface directly)
    try {
      this.cachedImage?.delete?.();
    } catch {}
    try {
      // CanvasKit.Surface.makeImageSnapshot() returns an Image
      this.cachedImage = this.surface.makeImageSnapshot();
    } catch (e) {
      this.cachedImage = null;
    }

    this.lastRenderedAt = performance.now();
    this.dirty = false;
    return true;
  }

  /** draw cached surface onto destination canvas */
  composeTo(canvas: any, bounds: {x:number,y:number,w:number,h:number}, dpr:number) {
    if (!this.surface && !this.cachedImage) return false;
    canvas.save();
    // draw image at bounds.x,bounds.y in logical pixels; canvas is already scaled by dpr in Renderer
    if (this.cachedImage) {
      // drawImage expects rect args in pixels of canvas coordinate system scaled by dpr.
      try {
        // If canvas is pre-scaled by dpr in Renderer, then passing bounds.x,bounds.y is correct.
        canvas.drawImage(this.cachedImage, bounds.x, bounds.y);
      } catch (e) {
        // fallback - try drawImageRect
        try {
          const src = this.cachedImage;
          canvas.drawImageRect(src, this.CanvasKit.LTRBRect(0, 0, this.width, this.height), this.CanvasKit.LTRBRect(bounds.x, bounds.y, bounds.x + bounds.w, bounds.y + bounds.h), null);
        } catch {}
      }
    } else if (this.surface) {
      // Some CanvasKit versions allow drawSurface; fallback to makeImageSnapshot then drawImage (expensive)
      try {
        const snap = this.surface.makeImageSnapshot();
        canvas.drawImage(snap, bounds.x, bounds.y);
        snap.delete();
      } catch (e) {
        // as last resort, skip composition
      }
    }
    canvas.restore();
    return true;
  }

  dispose() {
    try { this.cachedImage?.delete(); } catch {}
    try { this.surface?.dispose?.(); } catch {}
    this.surface = null;
    this.cachedImage = null;
  }
}
```

> 说明：CanvasKit 的不同版本在 `MakeCanvasSurface` API 上存在差异（有的是 `MakeCanvasSurface(canvasElement)`，有的支持 object param）。示例中做了 defensive coding；在你的工程中请替换为你使用的 CanvasKit 版本的正确创建方法（通常 `CanvasKit.MakeCanvasSurface(canvasElement)`）。

### `src/renderer/LayerManager.ts`

```ts
// LayerManager.ts
import type * as CanvasKitModule from 'canvaskit-wasm';
import { Layer, LayerPolicy } from './Layer';
import { Node } from '../scene/Node';

export class LayerManager {
  CanvasKit: any;
  engine: any;
  layers: Map<Node, Layer> = new Map();
  dpr = 1;
  stats = { hits: 0, misses: 0, created: 0 };

  constructor(CanvasKit: typeof CanvasKitModule, engineRef: any, dpr = 1) {
    this.CanvasKit = CanvasKit;
    this.engine = engineRef;
    this.dpr = dpr;
  }

  enableLayer(node: Node, policy?: LayerPolicy) {
    if (this.layers.has(node)) return this.layers.get(node)!;
    const layer = new Layer(this.CanvasKit, node, policy);
    this.layers.set(node, layer);
    this.stats.created++;
    // hook node to mark layer dirty on structural/transform/style changes
    (node as any).__layer = layer;
    return layer;
  }

  disableLayer(node: Node) {
    const l = this.layers.get(node);
    if (!l) return;
    l.dispose();
    this.layers.delete(node);
    delete (node as any).__layer;
  }

  markDirty(node: Node) {
    const layer = (node as any).__layer as Layer | undefined;
    if (layer) layer.markDirty();
    // propagate up: parent layers that include this node should be marked
    let p = node.parent;
    while (p) {
      const pl = (p as any).__layer as Layer | undefined;
      if (pl) pl.markDirty();
      p = p.parent;
    }
  }

  dispose() {
    for (const l of this.layers.values()) l.dispose();
    this.layers.clear();
  }

  /** Called by Renderer during render pass.
   *  returns an ordered list of render units: either {type:'layer',layer,bounds,z} or {type:'shape', shape,z}
   */
  buildRenderUnits(root: Node) {
    const units: any[] = [];
    // traverse but when encounter a node with layer, create unit and skip subtree
    const traverse = (node: Node) => {
      if (!node.visible) return;
      const l = (node as any).__layer as Layer | undefined;
      if (l) {
        // compute world bounds for the node
        const bounds = (node as any).getWorldBounds ? (node as any).getWorldBounds() : {x:0,y:0,w:100,h:100};
        units.push({ type: 'layer', layer: l, bounds, z: (node as any).globalZ ?? 0 });
        return; // skip subtree
      }

      if ((node as any).isShape) {
        units.push({ type: 'shape', shape: node, z: (node as any).globalZ ?? 0 });
      }

      for (const c of node.children) traverse(c);
    };

    traverse(root);
    // sort by z
    units.sort((a, b) => a.z - b.z);
    return units;
  }
}
```

> 注意：`getWorldBounds()`、`isShape`、`globalZ` 需要在 `Node/Shape` 中实现。`LayerManager` 通过 `__layer` 简单关联 node 与 Layer 实例。

// Node.ts (补充)
import { Matrix2D } from '../core/Matrix2D';

export class Node {
  // ... 原有字段
  name?: string;
  zIndex = 0;
  globalZ = 0;

### 修改 `src/renderer/Renderer.ts`（集成 LayerManager）

```ts
// Renderer.ts (关键片段)
import { LayerManager } from './LayerManager';

export class Renderer {
  ctx: RenderContext;
  layerManager: LayerManager;
  // ...

  constructor(ctx: RenderContext) {
    this.ctx = ctx;
    this.layerManager = new LayerManager(ctx.CanvasKit, null, ctx.dpr);
    this.layerManager.engine = this; // set reference if needed
  }

  render(root: Node) {
    const canvas = this.ctx.getCanvas();
    const ck = this.ctx.CanvasKit;

    root.updateWorldMatrix();
    root.updateGlobalZ?.();

    // build render units using layer manager
    const units = this.layerManager.buildRenderUnits(root);

    // iterate units in order
    for (const u of units) {
      if (u.type === 'layer') {
        const layer: any = u.layer;
        // compute bounds (with padding)
        const pad = layer.policy.padding ?? 2;
        const bounds = { x: u.bounds.x - pad, y: u.bounds.y - pad, w: u.bounds.w + pad*2, h: u.bounds.h + pad*2 };
        if (layer.dirty || !layer.surface) {
          // re-render subtree into layer.surface
          // provide a renderFn that draws only that subtree
          layer.renderToSurface((subroot, subcanvas, CanvasKit) => {
            // we need a mini-renderer that draws subtree without recursing into other layers
            // reuse existing renderer.collect/draw logic but restrict to subroot
            this._renderSubtreeToCanvas(subroot, subcanvas, CanvasKit);
          }, bounds, this.ctx.dpr);
          this.layerManager.stats.misses++;
        } else {
          this.layerManager.stats.hits++;
        }

        // compose layer into main canvas. main canvas is pre-scaled by dpr in outer render.
        layer.composeTo(canvas, bounds, this.ctx.dpr);

      } else if (u.type === 'shape') {
        // draw normal shape directly
        const s = u.shape;
        // draw shape with current renderer pipeline (use existing batching/paint pool)
        this._drawShapeDirect(canvas, s, ck);
      }
    }

    this.ctx.flush();
  }

  // draws subtree but ignore internal layers (they will be handled separately)
  private _renderSubtreeToCanvas(subroot: Node, canvas: any, CanvasKit: any) {
    // similar to normal drawing but when encountering nested layer-marked nodes, skip them.
    const drawNode = (node: Node) => {
      if (!node.visible) return;
      if ((node as any).__layer && (node as any).__layer.root !== subroot) {
        // a nested layer - skip drawing; its own layer will be composed separately
        return;
      }
      if ((node as any).isShape) {
        // draw shape on provided canvas
        (node as any).onDraw(canvas, CanvasKit);
      }
      for (const c of node.children) drawNode(c);
    };
    drawNode(subroot);
  }

  private _drawShapeDirect(canvas: any, shape: any, CanvasKit: any) {
    // same as before: ensure path, use paintPool, draw path
    shape.ensurePath && shape.ensurePath(CanvasKit);
    const path = shape._ckPath;
    const paint = shape.paintPool ? shape.paintPool.getFillPaintHex(shape.fillStyle) : null;
    if (paint) canvas.drawPath(path, paint);
    else {
      const p = new CanvasKit.Paint();
      p.setAntiAlias(true);
      p.setColor(CanvasKit.Color(255,0,0,1));
      p.setStyle(CanvasKit.PaintStyle.Fill);
      canvas.drawPath(path, p);
      p.delete();
    }
  }
}
```

> 说明：`_renderSubtreeToCanvas` 是用于在离屏 surface 上绘制子树的简化渲染器，它跳过任何在该子树内部标为独立 Layer 的节点（以避免重复绘制）。

# 六、Shape.getWorldBounds 示例实现（重要）

`Shape` 要能返回其世界包围盒，用来决定 layer 的 surface 大小。这里给出一个基于 path bounds 的简单实现（依赖 CanvasKit.Path.computeTightBounds 或 path.getBounds；不同版本 API 可能不同）。

```ts
// src/scene/Shape.ts (添加 / 修改 getWorldBounds)
getWorldBounds(CanvasKit: any) {
  // Ensure path exists
  if (!this._ckPath) {
    if (this.pathPool) this._ckPath = this.pathBuilder.buildIntoPool(this.pathPool);
    else this._ckPath = this.pathBuilder.build(CanvasKit);
  }
  // CanvasKit Path API may have getBounds or computeTightBounds
  try {
    const b = this._ckPath.getBounds ? this._ckPath.getBounds() : this._ckPath.computeTightBounds && this._ckPath.computeTightBounds();
    // b likely {left, top, right, bottom}
    const left = b.left ?? b[0] ?? 0;
    const top = b.top ?? b[1] ?? 0;
    const right = b.right ?? b[2] ?? left;
    const bottom = b.bottom ?? b[3] ?? top;
    // transform corners by worldMatrix to get axis-aligned bbox: approximate by transforming 4 corners
    const m = this.worldMatrix.array;
    const transformPoint = (x:number,y:number) => {
      const nx = m[0]*x + m[2]*y + m[4];
      const ny = m[1]*x + m[3]*y + m[5];
      return {x:nx, y:ny};
    };
    const p1 = transformPoint(left, top);
    const p2 = transformPoint(right, top);
    const p3 = transformPoint(right, bottom);
    const p4 = transformPoint(left, bottom);
    const xs = [p1.x,p2.x,p3.x,p4.x];
    const ys = [p1.y,p2.y,p3.y,p4.y];
    const minX = Math.min(...xs), maxX = Math.max(...xs);
    const minY = Math.min(...ys), maxY = Math.max(...ys);
    const res = { x: minX, y: minY, w: maxX - minX, h: maxY - minY };
    this.boundsCache = res;
    return res;
  } catch (e) {
    // fallback: return small bbox
    const r = { x:0, y:0, w:0, h:0 };
    this.boundsCache = r;
    return r;
  }
}
```

> 注意：computeTightBounds/getBounds 不同版本名称不同，请用你当前 CanvasKit 版本的 API。若没有此 API，可手动从 path commands 计算 bbox。

# 七、脏传播 & 自动触发

为了自动工作，必须在 Node 的变更点触发 `layerManager.markDirty(node)`。推荐做法：

* 在 `Node.markDirty()`（或 `setTransform()`、`setStyle()`、`add/remove`）处，如果 Engine 有 layerManager 的引用则调用 `engine.layerManager.markDirty(this)`。
* Engine 在 `attachResources(root)` 时可把 `__onMarkDirty = (n)=> this.layerManager.markDirty(n)` 注入到每个 node（或在 Node 构造时由 Engine 注册全局回调）。

示例注入（Engine.init）：

```ts
// in Engine.init after creating layerManager
const hook = (n:any) => { this.layerManager.markDirty(n); };
root.__onMarkDirty = hook;
function injectHook(node) {
  (node as any).__onMarkDirty = hook;
  for (const c of node.children) injectHook(c);
}
injectHook(this.root);
```

或者在 `Node.markDirty()` 中调用全局 `Engine.instance?.layerManager?.markDirty(this)`（如果你保持 Engine 单例）。

# 八、Surface 大小限制与切片策略（说明）

当 layer 的 bbox 超过 `policy.maxWidth` 或 `policy.maxHeight` 时：

* **方案 A（简单）**：禁止缓存（policy.mode = 'never'），LayerManager 返回 `cannot cache`，Renderer 会回退到逐帧绘制该子树（保正确性但牺牲性能）。
* **方案 B（高级）**：把大区域划分为 tiles（比如 2048×2048），为每个 tile 创建一个 surface 并缓存。合成时把每个 tile 逐个 compose 回主 canvas。实现复杂但可用于非常大 map 或图层。若你需要，我可以给出 tile slicing 的实现细节。

建议起步使用 **方案 A + 日志告警**，后期按需实现切片。

# 九、调试与指标

LayerManager 暴露统计（`layerManager.stats`）：

* `created`：创建 layer 数量
* `hits`：cache hit 次数（使用缓存）
* `misses`：cache miss 次数（重新渲染）
* `memUsageEstimate`：surface 总像素数 × 4 bytes（近似）

展示这些数据到 debug overlay 能帮助你调优 `maxWidth/maxHeight` 和哪些 layer 应该启用/禁用缓存。

# 十、集成示例（demo）

把下面代码加入 `src/examples/layer-demo.ts`（或修改现有 demo）：

```ts
// layer-demo.ts
import { Engine } from '../engine/Engine';
import { PathBuilder } from '../scene/PathBuilder';
import { Shape } from '../scene/Shape';

export async function run(engine: Engine) {
  await engine.init();

  // create a background large static panel -> enable layer to cache
  const bgPB = new PathBuilder();
  bgPB.add({cmd:'moveTo', x:0, y:0});
  bgPB.add({cmd:'lineTo', x:1200, y:0});
  bgPB.add({cmd:'lineTo', x:1200, y:800});
  bgPB.add({cmd:'lineTo', x:0, y:800});
  bgPB.add({cmd:'close'});
  const bg = new Shape(bgPB);
  bg.fillStyle = '#f7f7f7';
  engine.add(bg);
  // enable layer on bg
  engine.layerManager.enableLayer(bg, { mode: 'always', maxWidth: 2048, maxHeight: 2048, padding: 4 });

  // lots of dynamic small shapes (e.g., moving sprites) that should NOT be cached
  for (let i = 0; i < 300; i++) {
    const pb = new PathBuilder();
    pb.add({cmd:'arc', x: Math.random()*1000+50, y: Math.random()*600+50, r: 8});
    const s = new Shape(pb);
    s.fillStyle = '#007aff';
    engine.add(s);
  }

  // large decorative panel (static) -> cached
  const panelPB = new PathBuilder();
  panelPB.add({cmd:'moveTo', x:100, y:100});
  panelPB.add({cmd:'lineTo', x:500, y:100});
  panelPB.add({cmd:'lineTo', x:500, y:400});
  panelPB.add({cmd:'lineTo', x:100, y:400});
  panelPB.add({cmd:'close'});
  const panel = new Shape(panelPB);
  panel.fillStyle = '#ffffff';
  engine.add(panel);
  engine.layerManager.enableLayer(panel, { mode: 'auto', maxWidth: 1024, maxHeight: 1024, padding: 6 });

  engine.start();
}
```

运行后，你可以在控制台查看 `engine.layerManager.stats`，观察 hits/misses。

# 十一、注意事项与兼容性

1. **CanvasKit 版本差异**：Surface API、Path bounds API、drawImage API 可能在不同版本上差异，请用你当前安装的 `canvaskit-wasm` 版本对应 API 校正示例代码。
2. **DPR 相关**：主 canvas 在 Renderer 中通常通过 `canvas.scale(dpr,dpr)` 进行缩放；离屏 surface 的像素宽高需要与主 canvas 的显示密度一致以保证清晰度。
3. **内存**：大量离屏 surface 会占用较多 WASM/native 内存（像素 × 4 bytes）。使用 `maxWidth/maxHeight` 与 `LayerPolicy` 控制总内存。提供 `LayerManager.getEstimatedMemory()` 来统计。
4. **嵌套 Layer**：设计上允许嵌套 layer，但渲染时外层 layer 的离屏绘制会跳过内层子树（因为内层会单独渲染并组合）。注意脏传播时要同时标记内层与外层。
5. **滤镜与阴影**：若 layer 子树里包含需要在边界外绘制的滤镜（例如模糊阴影），需要把 padding 设置足够大以避免被裁切。

# 十二、后续优化建议（可选实现）

* **Tile-based Layer（切片）**：对超大层实现 2D 切片缓存 & LRU 策略。
* **Partial redraw（脏矩形）**：在 Layer 内部实现更精细的片段重绘（只 redraw 改变的 tiles）。
* **Layer merging**：针对相邻且静态的 layer 合并成单个 surface 降低合成调用。
* **GPU-backed caching（未来）**：如果转向 WebGPU 后端，可用纹理 atlas 进一步提升合成性能。
