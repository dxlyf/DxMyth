## 🧠 四、功能分层与类设计（详细）

### 1️⃣ Core 模块（基础数据结构）

| 文件                | 功能                                    |
| ----------------- | ------------------------------------- |
| `Vec2.ts`         | 二维向量运算                                |
| `Matrix2D.ts`     | 仿射矩阵（translate、rotate、scale、multiply） |
| `Rect.ts`         | 矩形与交集/合并运算                            |
| `Color.ts`        | RGBA 转换与 CanvasKit.Color 封装           |
| `Transform.ts`    | 统一节点变换结构（position, scale, rotation）   |
| `EventEmitter.ts` | 简单事件系统（on/off/emit）                   |

---

### 2️⃣ Scene 模块（场景图）

| 文件               | 功能                                                      |
| ---------------- | ------------------------------------------------------- |
| `Node.ts`        | 所有显示对象基类，包含 transform、children、visible、opacity、update() |
| `Shape.ts`       | 通用矢量图形节点，持有 Path + Paint                                |
| `Group.ts`       | 子节点容器，管理层级与 transform 叠加                                |
| `ImageNode.ts`   | 图像节点，封装 CanvasKit.Image                                 |
| `TextNode.ts`    | 文本节点，封装 CanvasKit.Paragraph 或 Font                      |
| `PathBuilder.ts` | 封装路径命令，惰性构建 CanvasKit.Path                              |

**示例结构：**

```ts
class Shape extends Node {
  pathBuilder: PathBuilder;
  path?: CanvasKit.Path;
  fillPaint?: CanvasKit.Paint;
  strokePaint?: CanvasKit.Paint;
  onDraw(canvas: CanvasKit.Canvas) {
    if (this.fillPaint) canvas.drawPath(this.path!, this.fillPaint);
    if (this.strokePaint) canvas.drawPath(this.path!, this.strokePaint);
  }
}
```

---

### 3️⃣ Renderer 模块（渲染）

| 文件                 | 功能                                     |
| ------------------ | -------------------------------------- |
| `Renderer.ts`      | 递归绘制场景树，管理 surface、flush、dirty rect    |
| `RenderContext.ts` | 封装 CanvasKit.Surface、Canvas、PixelRatio |
| `PaintPool.ts`     | 管理 Paint 复用与共享（按样式 key）                |
| `RasterCache.ts`   | 离屏缓存（Surface/Image）复用                  |
| `Layer.ts`         | 可选的离屏渲染层（clip、blend、filter）            |

---

### 4️⃣ Events 模块（事件）

| ---------------------- | --------------------------------- |

| `PointerDispatcher.ts` | 监听 DOM pointer 事件，转发给 Scene       |
| `EventSystem.ts`       | 实现冒泡/捕获机制、dispatch 流程             |

## ⚙️ 五、引擎主类设计（Engine.ts）

```ts
class Engine {
  canvas: HTMLCanvasElement;
  surface: CanvasKit.Surface;
  renderer: Renderer;
  ticker: Ticker;
  root: Node;

  constructor(options: EngineOptions) { ... }
  render() { this.renderer.render(this.root); }
  start() { this.ticker.add(() => this.render()); }
  dispose() { this.surface?.delete(); }
}
```

## 🧰 七、性能优化清单

* ✅ 复用 Paint / Path / Matrix / Rect
* ✅ 避免每帧 JS→WASM 调用（批量绘制）
* ✅ Layer 合批绘制（相同 Paint、blend 模式）
* ✅ 离屏缓存静态节点
* ✅ Matrix 采用脏标记惰性计算
* ✅ 提供 DebugOverlay 查看 draw call、cache 命中率
