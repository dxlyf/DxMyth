非常好 ✅
我们现在要在 `LayerManager` 的基础上，实现 **Tile-based Layer（切片层缓存）**——也就是当 Layer 的绘制区域超过单个离屏 surface 的上限（例如 2048×2048）时，自动把它拆分成多个 tile（平铺块）分别缓存和合成。

---

## 🚀 总体目标

让每个 `Layer` 能够在超大内容（如大型地图、长列表、复杂背景）下，
仍然支持局部缓存和增量重绘，而不因为尺寸超限而完全失效。

---

## 🧩 设计思路概述

我们把一个 Layer 的离屏缓存拆成若干个 tile：

```
Layer (logical area)
 ├─ Tile[0,0]  (surface 2048×2048)
 ├─ Tile[1,0]  (surface 2048×2048)
 ├─ Tile[0,1]
 ├─ Tile[1,1]
 └─ ...
```

每个 tile 对应：

* 一个离屏 `CanvasKit.Surface`
* 一个 world-space 区域（tileRect）
* 一个 dirty 标记（只在其覆盖的子内容改变时重绘）
* 可选快照（`makeImageSnapshot()`）

---

## ⚙️ Tile-based Layer 类结构

我们将 `Layer` 拆成两种子类：

```ts
class LayerBase { ... }     // 原始 Layer 抽象基类
class SimpleLayer extends LayerBase { ... } // 单surface (原实现)
class TiledLayer extends LayerBase { ... }  // 多surface tile 实现
```

`LayerManager.enableLayer()` 根据 bounds 大小或 policy 决定使用哪种类型：

```ts
if (bounds.w > maxWidth || bounds.h > maxHeight)
    layer = new TiledLayer(CanvasKit, node, policy);
else
    layer = new SimpleLayer(CanvasKit, node, policy);
```

## 🏗️ Tile 数据结构

```ts
type TileEntry = {
  x: number;  // tile 索引 X
  y: number;  // tile 索引 Y
  rect: { x:number; y:number; w:number; h:number }; // 世界空间区域
  surface: any;    // CanvasKit.Surface
  image?: any;     // CanvasKit.Image
  dirty: boolean;
};
```

## 📜 完整实现代码（TiledLayer.ts）

放在 `src/renderer/TiledLayer.ts`：

```ts
import { Layer } from "./Layer";
import type * as CanvasKitModule from "canvaskit-wasm";
import { Node } from "../scene/Node";

export class TiledLayer extends Layer {
  tiles: TileEntry[] = [];
  tileSize = 2048;
  bounds: {x:number,y:number,w:number,h:number} = {x:0,y:0,w:0,h:0};

  constructor(CanvasKit: typeof CanvasKitModule, root: Node, policy?: any) {
    super(CanvasKit, root, policy);
    this.tileSize = policy?.tileSize ?? 2048;
  }

  /** 初始化或重新划分 tiles */
  ensureTiles(bounds: {x:number,y:number,w:number,h:number}, dpr:number) {
    const ts = this.tileSize;
    const cols = Math.ceil(bounds.w / ts);
    const rows = Math.ceil(bounds.h / ts);

    const tiles: TileEntry[] = [];
    for (let ty = 0; ty < rows; ty++) {
      for (let tx = 0; tx < cols; tx++) {
        const x = bounds.x + tx * ts;
        const y = bounds.y + ty * ts;
        const w = Math.min(ts, bounds.w - tx * ts);
        const h = Math.min(ts, bounds.h - ty * ts);
        tiles.push({
          x: tx,
          y: ty,
          rect: {x, y, w, h},
          surface: null,
          dirty: true,
        });
      }
    }
    this.tiles = tiles;
    this.bounds = bounds;
  }

  /** 为每个 tile 创建 surface */
  private ensureSurface(tile: TileEntry, dpr:number) {
    const ck = this.CanvasKit;
    const tw = Math.round(tile.rect.w * dpr);
    const th = Math.round(tile.rect.h * dpr);
    if (!tile.surface) {
      const c = document.createElement('canvas');
      c.width = tw;
      c.height = th;
      tile.surface = ck.MakeCanvasSurface(c);
    }
  }

  /** 渲染脏 tile */
  renderToSurface(renderFn: (root: Node, canvas:any, CanvasKit:any, clipRect:any)=>void, bounds:{x:number,y:number,w:number,h:number}, dpr:number) {
    if (!this.tiles.length) this.ensureTiles(bounds, dpr);
    for (const tile of this.tiles) {
      this.ensureSurface(tile, dpr);
      if (!tile.dirty) continue;
      const canvas = tile.surface.getCanvas();
      canvas.clear(this.CanvasKit.Color(0,0,0,0));
      canvas.save();
      canvas.scale(dpr, dpr);
      canvas.translate(-tile.rect.x, -tile.rect.y);
      // 裁剪只绘制该 tile 的区域
      canvas.clipRect(this.CanvasKit.LTRBRect(tile.rect.x, tile.rect.y, tile.rect.x+tile.rect.w, tile.rect.y+tile.rect.h), this.CanvasKit.ClipOp.Intersect, true);
      renderFn(this.root, canvas, this.CanvasKit, tile.rect);
      canvas.restore();
      tile.surface.flush();

      // 可选：缓存图像快照以减少后续 flush
      try {
        tile.image?.delete?.();
        tile.image = tile.surface.makeImageSnapshot();
      } catch {}
      tile.dirty = false;
    }
    this.dirty = false;
  }

  /** 合成到主 canvas */
  composeTo(canvas:any, bounds:{x:number,y:number,w:number,h:number}, dpr:number) {
    for (const tile of this.tiles) {
      const img = tile.image;
      if (!img) continue;
      canvas.drawImageRect(
        img,
        this.CanvasKit.LTRBRect(0, 0, tile.rect.w * dpr, tile.rect.h * dpr),
        this.CanvasKit.LTRBRect(tile.rect.x, tile.rect.y, tile.rect.x+tile.rect.w, tile.rect.y+tile.rect.h),
        null
      );
    }
  }

  markTileDirtyByRect(rect:{x:number,y:number,w:number,h:number}) {
    for (const tile of this.tiles) {
      const t = tile.rect;
      const overlap = !(t.x > rect.x + rect.w || t.x + t.w < rect.x || t.y > rect.y + rect.h || t.y + t.h < rect.y);
      if (overlap) tile.dirty = true;
    }
    this.dirty = true;
  }

  dispose() {
    for (const tile of this.tiles) {
      try { tile.image?.delete?.(); } catch {}
      try { tile.surface?.dispose?.(); } catch {}
    }
    this.tiles = [];
  }
}
```

## 🧠 渲染逻辑更新（LayerManager + Renderer）

### 在 `LayerManager.enableLayer()` 中判断是否使用 TiledLayer

```ts
import { TiledLayer } from './TiledLayer';

enableLayer(node: Node, policy?: LayerPolicy) {
  if (this.layers.has(node)) return this.layers.get(node)!;

  // 初步估算 bounds
  const bounds = node.getWorldBounds ? node.getWorldBounds() : {w:0,h:0};
  const tooLarge = (bounds.w > (policy?.maxWidth ?? 2048)) || (bounds.h > (policy?.maxHeight ?? 2048));
  const layer = tooLarge
      ? new TiledLayer(this.CanvasKit, node, policy)
      : new Layer(this.CanvasKit, node, policy);

  this.layers.set(node, layer);
  this.stats.created++;
  (node as any).__layer = layer;
  return layer;
}
```

## 🧩 渲染器调用保持不变

`Renderer.render()` 中依然调用：

layer.renderToSurface(renderFn, bounds, this.ctx.dpr);
layer.composeTo(canvas, bounds, this.ctx.dpr);

`TiledLayer` 的实现会自动处理 tile 逻辑。

## 🔍 脏矩形标记

当节点改变时（例如动画移动或局部更新），可以只标记部分 tile 脏：

```ts
layer.markTileDirtyByRect(changedRect);
```

如果不关心局部，可以直接 `layer.markDirty()`，它会导致所有 tile 全部重绘。

## 💡 示例演示（大尺寸场景）

```ts
// layer-tile-demo.ts
import { Engine } from '../engine/Engine';
import { Shape } from '../scene/Shape';
import { PathBuilder } from '../scene/PathBuilder';

export async function run(engine: Engine) {
  await engine.init();

  // 一个 6000x4000 的大地图层
  const mapPB = new PathBuilder();
  mapPB.add({cmd:'rect', x:0, y:0, w:6000, h:4000});
  const map = new Shape(mapPB);
  map.fillStyle = '#fafafa';
  engine.add(map);

  // 开启切片 Layer 缓存
  engine.layerManager.enableLayer(map, {
    mode:'always',
    maxWidth:2048,
    maxHeight:2048,
    tileSize:1024
  });

  // 动态标记小区域更新（模拟编辑）
  setInterval(()=>{
    const rx = Math.random()*5000+200;
    const ry = Math.random()*3000+200;
    map.__layer?.markTileDirtyByRect({x:rx,y:ry,w:200,h:200});
  }, 1000);

  engine.start();
}
```

## 🧮 内存估算

每个 tile surface 占用约：
`(tileSize * tileSize * 4 bytes)`
例如 tileSize=1024 → 单 tile ≈ 4MB。
所以 4×4 = 16 tile 的大 Layer ≈ 64MB。
建议 tileSize = 512 或 1024 之间权衡。

---

## ✅ 优点总结

| 特性         | SimpleLayer         | TiledLayer           |
| ---------- | ------------------- | -------------------- |
| Surface 限制 | 受限于 maxWidth/Height | 自动切片                 |
| 局部重绘       | 否                   | ✅ 按 tile             |
| 内存控制       | 简单                  | 可灵活按需创建              |
| 合成性能       | 单 drawImage         | 多 tile drawImageRect |
| 适用场景       | 小面板、背景              | 大地图、复杂UI、滚动区域        |

## 📦 下一步可选增强

1. **Tile LRU 缓存策略**

   * 仅保留最近访问或可见区域的 tile surface，其他 tile 自动释放（按需重建）。
2. **视口裁剪渲染**

   * 在合成阶段只绘制可见 tile（避免 drawImageRect 超视口部分）。
3. **Tile 优先级渲染队列**

   * 优先重绘最近 dirty 且在视口内的 tile，后台渐进更新远处 tile。
