## 🧩 目标回顾

目前：

* 每个 `Shape` 需要手动注入 `paintPool`、`pathPool`。
* `PathBuilder` 每次 build 都会重新构建 Path 对象，即使版本已过期，也不会自动缓存复杂路径。

我们要实现：

1. **Engine 自动注入池资源**，用户不用关心。
2. **PathBuilder + LRU 缓存系统**：

   * 对于大型路径（复杂曲线/多边形），自动缓存最近使用的 N 个 Path。
   * 如果路径被重用（相同 commands hash），从缓存中直接取出。
   * 如果缓存已满，最旧的 Path 会 `.delete()` 释放。

# ✅ 第 3 部分：Engine 自动注入资源

### 修改文件：`src/engine/Engine.ts`

我们给 `Engine` 添加一个 `attachResources(node)` 方法：

* 递归遍历子树
* 如果节点是 `Shape`，注入 `paintPool` 与 `pathPool`
* 在 `add()` / `setRoot()` / `render()` 前调用确保注入完成

```ts
// src/engine/Engine.ts
import { Node } from '../scene/Node';
import { Shape } from '../scene/Shape';
import { PaintPool } from '../renderer/PaintPool';
import { PathPool } from '../renderer/PathPool';
import { Renderer } from '../renderer/Renderer';
import { RenderContext } from '../renderer/RenderContext';
import CanvasKitInit from 'canvaskit-wasm';

export class Engine {
  canvasKit: any;
  context!: RenderContext;
  renderer!: Renderer;
  paintPool!: PaintPool;
  pathPool!: PathPool;
  root: Node = new Node();
  ticker: any;
  options: { canvas: HTMLCanvasElement; dpr?: number };

  constructor(options: { canvas: HTMLCanvasElement; dpr?: number }) {
    this.options = options;
  }

  async init() {
    this.canvasKit = await CanvasKitInit({
      locateFile: (f) => `/node_modules/canvaskit-wasm/bin/${f}`,
    });
    this.context = new RenderContext(this.canvasKit, this.options.canvas, this.options.dpr ?? 1);
    this.renderer = new Renderer(this.context);
    this.paintPool = new PaintPool(this.canvasKit);
    this.pathPool = new PathPool(this.canvasKit);

    // 可选：初始化 ticker
    this.ticker = { onTick: () => this.render() };
  }

  /** 自动注入 PaintPool / PathPool 到 Shape 节点 */
  attachResources(node: Node) {
    if ((node as any).paintPool !== undefined) {
      (node as any).paintPool = this.paintPool;
      (node as any).pathPool = this.pathPool;
    }
    for (const child of node.children) {
      this.attachResources(child);
    }
  }

  /** 添加到 root 时自动注入 */
  add(node: Node) {
    this.attachResources(node);
    this.root.add(node);
  }

  render() {
    // 在每次渲染前保证注入一致性
    this.attachResources(this.root);
    this.renderer.render(this.root);
  }

  dispose() {
    // 释放所有资源
    this.root.dispose?.();
    this.paintPool?.dispose();
    this.pathPool?.dispose();
    this.context?.dispose();
  }
}
```

这样，用户在 demo 里只需：

```ts
const rect = new Shape(pb);
engine.add(rect);
```

就能自动使用 Engine 的 PaintPool / PathPool。

# ✅ 第 4 部分：LRU Path 缓存系统

LRU 机制适用于：

* 路径复杂且重复使用；
* 不频繁修改；
* 场景中有上千个 Shape。

我们将实现一个简单的 LRU 管理器：
`src/utils/LRUCache.ts`
以及修改 `PathBuilder` 支持使用它。

---

## 新文件：`src/utils/LRUCache.ts`

```ts
// src/utils/LRUCache.ts
export class LRUCache<K, V> {
  private capacity: number;
  private map: Map<K, V>;

  constructor(capacity: number) {
    this.capacity = capacity;
    this.map = new Map();
  }

  get(key: K): V | undefined {
    const value = this.map.get(key);
    if (value !== undefined) {
      // refresh order
      this.map.delete(key);
      this.map.set(key, value);
    }
    return value;
  }

  set(key: K, value: V, onEvict?: (key: K, value: V) => void) {
    if (this.map.has(key)) this.map.delete(key);
    this.map.set(key, value);
    if (this.map.size > this.capacity) {
      const firstKey = this.map.keys().next().value;
      const firstVal = this.map.get(firstKey)!;
      this.map.delete(firstKey);
      if (onEvict) onEvict(firstKey, firstVal);
    }
  }

  clear(onEvict?: (key: K, value: V) => void) {
    if (onEvict) {
      for (const [k, v] of this.map) onEvict(k, v);
    }
    this.map.clear();
  }

  size() {
    return this.map.size;
  }
}
```

## 修改文件：`src/scene/PathBuilder.ts`

增加对 LRU 缓存的支持。

```ts
// src/scene/PathBuilder.ts
import type * as CanvasKitModule from 'canvaskit-wasm';
import { PathPool } from '../renderer/PathPool';
import { LRUCache } from '../utils/LRUCache';

export type PathCommand =
  | { cmd: 'moveTo'; x: number; y: number }
  | { cmd: 'lineTo'; x: number; y: number }
  | { cmd: 'arc'; x: number; y: number; r: number }
  | { cmd: 'close' };

export class PathBuilder {
  static cache = new LRUCache<string, any>(128); // 全局 LRU 缓存（128条路径）
  commands: PathCommand[] = [];
  version = 0;

  add(cmd: PathCommand) {
    this.commands.push(cmd);
    this.version++;
  }

  clear() {
    this.commands.length = 0;
    this.version++;
  }

  private hashCommands(): string {
    return this.commands.map(c => JSON.stringify(c)).join(';');
  }

  build(CanvasKit: typeof CanvasKitModule) {
    const key = this.hashCommands();
    const cached = PathBuilder.cache.get(key);
    if (cached) return cached;

    const path = new CanvasKit.Path();
    for (const c of this.commands) this.applyCmd(path, c);
    PathBuilder.cache.set(key, path, (_, old) => old.delete());
    return path;
  }

  buildIntoPool(pathPool: PathPool) {
    const key = this.hashCommands();
    const cached = PathBuilder.cache.get(key);
    if (cached) return cached;

    const p = pathPool.acquire();
    try { p.rewind(); } catch {}
    for (const c of this.commands) this.applyCmd(p, c);
    PathBuilder.cache.set(key, p, (_, old) => {
      try { old.delete(); } catch {}
    });
    return p;
  }

  private applyCmd(p: any, c: PathCommand) {
    if (c.cmd === 'moveTo') p.moveTo(c.x, c.y);
    else if (c.cmd === 'lineTo') p.lineTo(c.x, c.y);
    else if (c.cmd === 'arc') {
      if (p.addCircle) p.addCircle(c.x, c.y, c.r, 1);
    } else if (c.cmd === 'close') p.close();
  }
}
```

### 🔍 工作原理

* 每条路径根据其 commands（序列化为字符串）生成唯一 hash；
* `PathBuilder.cache`（全局静态）存储最近 128 条不同路径；
* 如果命中缓存，则直接返回旧 Path；
* 如果缓存超出容量，最久未使用的 Path 会 `.delete()`；
* 对于复杂但重复的路径（如 UI 元件、按钮形状），性能提升非常明显。
