我们现在进入 **阶段 5：ShapeBatcher 批量渲染系统** —— 这是整个 CanvasKit 引擎中最能提升性能的关键优化点之一。

---

## 🎯 目标：让 Renderer 一次性绘制多个 Shape

当前的问题：

* 每个 `Shape` 都单独调用一次 `canvas.drawPath()`；
* 当有上千个节点时，会造成大量 JavaScript → WebAssembly 调用；
* 这些调用比 GPU 绘制本身更慢。

**目标：**

* 将使用相同 `Paint` 属性的 Shape 合并为一个批次；
* 对每个批次只调用一次 `drawPath()`；
* 内部仍保留每个 Shape 的 `Path` 引用（不重新构建）。

---

## 🧩 实现原理（概念）

我们新增一个模块：

```
src/renderer/
├── Renderer.ts         // 调用 Batcher
├── ShapeBatcher.ts     // 批次分组与绘制
└── PaintKey.ts         // 根据 Paint 属性生成唯一键
```

思路：

1. Renderer 收集所有要渲染的 Shape；
2. 按 PaintKey（颜色、描边、透明度、blendMode 等）分组；
3. 对每组调用一次 `canvas.drawPath(path, paint)`；
4. 批量绘制结束后 flush。

## 📁 新文件：`src/renderer/PaintKey.ts`

用于生成可哈希的 Paint 标识：

```ts
// src/renderer/PaintKey.ts
import type * as CanvasKit from 'canvaskit-wasm';

export class PaintKey {
  static from(paint: any) {
    const color = paint.getColor
      ? JSON.stringify(paint.getColor())
      : paint._cachedColor || '';
    const style = paint.getStyle ? paint.getStyle() : '';
    const strokeWidth = paint.getStrokeWidth ? paint.getStrokeWidth() : '';
    const alpha = paint.getAlphaf ? paint.getAlphaf() : '';
    const blend = paint.getBlendMode ? paint.getBlendMode() : '';
    return `${color}-${style}-${strokeWidth}-${alpha}-${blend}`;
  }
}
```

> ⚡️ 优化：CanvasKit 的 Paint 没有直接 hash 函数，我们人工拼接一个字符串 key 即可。

## 📁 新文件：`src/renderer/ShapeBatcher.ts`

```ts
// src/renderer/ShapeBatcher.ts
import { PaintKey } from './PaintKey';
import type * as CanvasKit from 'canvaskit-wasm';

export interface BatcherItem {
  path: any;
  paint: any;
}

export class ShapeBatcher {
  private groups: Map<string, BatcherItem[]> = new Map();
  private CanvasKit: typeof CanvasKit;

  constructor(CanvasKit: typeof CanvasKit) {
    this.CanvasKit = CanvasKit;
  }

  /** 收集 shape（自动分组） */
  add(path: any, paint: any) {
    const key = PaintKey.from(paint);
    if (!this.groups.has(key)) this.groups.set(key, []);
    this.groups.get(key)!.push({ path, paint });
  }

  /** 绘制所有批次 */
  draw(canvas: any) {
    for (const [, list] of this.groups) {
      // 取第一个 Paint 用于整个批次
      const paint = list[0].paint;
      for (const { path } of list) {
        canvas.drawPath(path, paint);
      }
    }
  }

  /** 清空当前批次 */
  clear() {
    this.groups.clear();
  }
}
```

## 📁 修改文件：`src/renderer/Renderer.ts`

我们让 Renderer 调用 ShapeBatcher 来统一绘制：

```ts
// src/renderer/Renderer.ts
import type * as CanvasKit from 'canvaskit-wasm';
import { Node } from '../scene/Node';
import { Shape } from '../scene/Shape';
import { RenderContext } from './RenderContext';
import { ShapeBatcher } from './ShapeBatcher';

export class Renderer {
  context: RenderContext;
  batcher: ShapeBatcher;

  constructor(context: RenderContext) {
    this.context = context;
    this.batcher = new ShapeBatcher(context.CanvasKit);
  }

  render(root: Node) {
    const { surface, canvas } = this.context;
    if (!surface || !canvas) return;

    canvas.clear([1, 1, 1, 1]); // 白底，可改背景色
    this.batcher.clear();

    this.collect(root);

    // 一次性绘制所有批次
    this.batcher.draw(canvas);

    surface.flush();
  }

  private collect(node: Node) {
    if (node instanceof Shape) {
      const path = node.path ?? node.pathBuilder?.buildIntoPool(node.pathPool);
      const paint = node.paint ?? node.paintPool?.acquire();
      if (path && paint) this.batcher.add(path, paint);
    }
    for (const child of node.children) this.collect(child);
  }
}
```

| 场景           | 优化前                 | 优化后               |
